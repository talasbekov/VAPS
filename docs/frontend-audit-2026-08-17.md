# Аудит фронтенда PersonalRecordFront — 17.08.2026

Восемь параллельных проходов: доступность, состояния/обратная связь, адаптивность,
дизайн-система, производительность, формы, навигация/IA, живой визуальный проход
по поднятому стенду (Next :3106 + Django :8100, персона `admin`).

Стек: Next.js 15.2.4 (App Router), React 19, Tailwind **3.4.18**, shadcn/ui (new-york),
Radix, TanStack Query v5, next-auth, lucide-react, framer-motion, FullCalendar.
Объём: 43 маршрута, 135 `.tsx` в прикладных слоях, 66 `useQuery`, ~24 формы.

Ориентир из ui-ux-pro-max: Minimalism/Swiss, enterprise dashboard,
variance 3 / motion 3 / density 8. Стиль в целом ему соответствует —
проблемы не в направлении, а в исполнении.
