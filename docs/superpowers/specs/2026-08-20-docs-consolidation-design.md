Дата: 2026-08-20. Утверждён: вариант A («эталон сначала, потом веерный аудит»).

## Источник истины (приоритет)
1. `Прототип/` (экспорт Claude Design от 20.08.2026, `VAPS Prototype.dc.html` + Дежурства/КалендарьСмен/Объекты) — названия экранов и флоу.
2. Реальный код: `frontend/` + `Backend/` — терминология модулей.
3. Существующая документация — только материал для аудита.

## Инвариант (не нарушать)
Прототипный модуль «Сотрудники и штат» в реальном фронте = 4 модуля: «Статусы сотрудников», «Обзор», «Структура организации», «Отчеты». В документации фиксируется реальная структура (4 модуля) с пометкой о прототипном объединении. Модули не переименовывать.

## Скоуп аудита
Включено: `docs/`, `obsidian-vault/`, `_bmad-output/`, корневые md, `Backend/**/*.md`, `spikes/**/*.md`, `deploy/**/*.md`, `frontend/**/*.md`, материалы Smart Josparlau (папки, master prompt, zip'ы — как документация для классификации).
Исключено: `.claude/`, `.agents/`, `graphify-out/`, `_bmad/` (фреймворк), `.git/`, node_modules.

## Процесс
- **Этап 1 (только чтение)**: построить эталон (модули/экраны/флоу/термины из прототипа; модули из frontend; apps/API из Backend) → веер Explore-агентов по директориям с единым эталоном и форматом ответа → сводная таблица (файл → класс → действие → причина) + список противоречий «прототип vs код» вопросами пользователю. Классы: АКТУАЛЬНО / УСТАРЕЛО / ДУБЛИКАТ / ПРОТИВОРЕЧИТ / МУСОР.
- **Этап 2 (СТОП-гейт)**: целевое дерево vault, единый frontmatter (`title`, `module`, `updated`, tags), маппинг слияний, отдельный список на удаление. Ждать явного «поехали».
- **Этап 3**: переписать/слить в `obsidian-vault/` (русский язык, wiki-ссылки `[[...]]`), фичи вне прототипа и кода → `_backlog-unverified.md`; удаление смешанно: явный мусор (zip, пустышки, дубликаты) — физически, содержательное устаревшее — `obsidian-vault/Archive/` с пометкой; финальный отчёт + коммит.
