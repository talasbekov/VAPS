# UX/UI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. The user explicitly chose autonomous work; design decisions and execution are delegated to the implementer.

**Goal:** Исправить воспроизведённые неудобства навигации, широких таблиц, справочников и расстановки.

**Architecture:** Сохранить существующие страницы и права. Для справочников добавить общую оболочку вокруг текущих редакторов; для расстановки использовать URL текущей страницы и клиентский отбор уже загруженных постов.

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind, TanStack Query, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-12-ux-ui-design.md`

## Global Constraints

- Без миграций, изменения рабочей базы, ролевых правил, публикации или обновления серверной поставки.
- Стенд разработки 3352, собственный каталог сборки.
- UX-пробы блокируют бизнес-записи; настоящие чтения и подменённые ответы учитываются отдельно.
- Названия, адреса и счётчики справочников берутся из серверного реестра.
- Общие потребность и назначения расстановки считаются по полному составу выбранного объекта.

## Review Focus

- Права не загрузились или отозваны: новые элементы не должны использовать закэшированный доступ.
- Специализированные справочники имеют серверный `screen`, а не generic-адрес по коду.
- Несуществующий пост или пост другого объекта в URL не должен подменять выбранный объект.
- Длинные названия, пустые результаты, узкие экраны сохраняют доступ к выбору и сбросу.
- Просмотр старого этапа не должен приводить к бизнес-записи из нового элемента интерфейса.
