# Подтверждение смены точки с несохранёнными координатами

**Goal:** Смена «Точка для» в офлайн-карте не стирает введённые координаты без явного решения пользователя.

**Design:** Сравнивать текущие строки координат со снимком начала редактирования. Чистая форма переключается сразу; изменённая, включая частичный/некорректный ввод, предлагает остаться или перейти со сбросом. До подтверждения select и draft остаются прежними. Cancel/Escape/X возвращают фокус select, подтверждение использует сохранённую позицию новой цели. Dialog закрывается при скрытии карты/потере редактирования/смене области, возвращение само его не открывает. Pending save не позволяет смену. Смена объекта посещения остаётся прежним отдельным scope-reset; этот этап защищает выбор цели внутри текущего объекта.
