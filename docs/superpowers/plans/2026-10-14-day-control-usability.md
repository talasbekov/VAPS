# Дневная проверка контроля и выгрузка сводок

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** До 16:00 Asia/Qyzylorda подготовить проверенную локальную версию с CSV сводок по видам/сотрудникам, повторить полный сценарий длительной работы и дать пользователю проверенные учётки с понятными сценариями.

**Architecture:** Сводки уже вычисляет PostgreSQL в одном снимке и возвращает все группы независимо от страниц записей. Клиент получает новый снимок через существующий защищённый query.refetch и формирует CSV без новых серверных расчётов. Обычный CSV записей остаётся отдельной серверной выгрузкой.

**Tech Stack:** Next15, React, TanStack Query5, TypeScript, Playwright; существующий Django/PostgreSQL API.

**Spec:** Bounded design in current session: отдельная кнопка «Выгрузить сводку CSV» на вкладках «По видам»/«По сотрудникам», весь отбор, свежие серверные значения и права, неизвестное время отдельно от нуля, пояснение пересечений и контекст в файле. Пользователь поручил автономное продолжение; повторного запроса разрешения на эти обратимые изменения не требуется.
