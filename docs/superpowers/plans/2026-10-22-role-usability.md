# Удобная работа по ролям — план реализации

> Исполнение: ROOT ведёт навигацию, старт и установку; независимые задачи помощника и инструкции ролей делегированы. Используются существующие экраны, права и API. Повторного разрешения на локальные правки не требуется: пользователь прямо поручил выполнить работу.

**Цель:** сотрудник после входа видит несколько понятных рабочих действий, может найти остальные разрешённые разделы и выполнить свой следующий шаг без изучения структуры всего проекта.

**Архитектура:** новый стартовый экран объединяет ссылки на существующие рабочие процессы. Чистая модель действий применяет существующий `moduleOpenFor`; меню и старт используют её, а страничные/API-гейты остаются действующими. Формы помощника раскрывают дополнительные сведения по необходимости. Backend и назначения production не меняются.

**Технологии:** Next/React/TypeScript, существующие Node tests и Playwright, локальные Docker-сборки без сети.

**Основание:** поручение пользователя от22.10 об удобстве для неопытных пользователей, подтверждённая область «сначала полностью Smart Жоспарлау». Известные проблемы:25–27 ссылок, одинаковые названия поручений, ID в первом поле, двойная мобильная оболочка, отсутствие помощника у обычного профиля начальника департамента.
