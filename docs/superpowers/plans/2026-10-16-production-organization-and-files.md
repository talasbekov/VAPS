# Production organization data and legacy files repair

**Goal:** Исправить подтверждённые пользователем8неверных parent/type в части0111 и очистить старые полные офлайн-поставки отдельным небольшим дополнением, без повторной установки Docker-образов.

**Evidence:** Продовая690СГОorganization;716часть0111department→690;761/762/767directorate→716.693/694/695/696/702/703/704/711department→690 ошибочно. Второй SELECT не содержит Управления части0111,1отдела1управления и1отдела2управления.691часть0116department→690 и её отделы726/727/728/729/734/735/749 уже вложены; их автоматически не менять.

**Design:** Два независимых stdlib инструмента. Организационный patch фиксирует конкретные IDs/имена/исходные связи и не затрагивает прочие подразделения. Промежуточные узлы ищутся по точным разрешённым именам/коду под подтверждённым родителем; создаются лишь при отсутствии и однозначности. Default check только читает. Apply под общей updater lock: окно обслуживания, остановка приложения/писателей, backup, восстановление/репетиция на изолированной БД, один атомарный patch с locks и сверкой всех старых данных, затем запуск и повторная проверка. Недетерминированный исход записи оставляет приложение/lock закрытыми, без auto-restore. Старые ID/code/import/date/staff/status/roles сохраняются. Разрешённые изменения существующих divisions:8parent/type и служебные MPTT поля всего дерева; новых узлов не более3. Типы691/716 пока department для прежнего контракта расхода; новые migration/enum не вводятся.

**Cleanup design:** После уже успешного update16Oct проверить SUCCESS/живые образы/volume и общий lock. Узнавать старые полные поставки по root/source SHA manifests. Неактивные проверенные папки удалять только после сохранения их конфигурации в защищённой backup-папке; active/контейнерные пути/unknown data/backup/symlinks/mounts сохранять. Текущая/последняя предыдущая app-версия и последняя полная rollback-поставка сохраняются. Удаление только перечисленных проверенных файлов и пустых каталогов, никаких Docker prune/rm/volume операций.
