# Читаемый паспорт на узком экране

**Goal:** Название объекта использует ширину карточки на телефоне; фотография и её действие компактны. Длинные значения общих данных читаются без тесного соседства с подписями.

**Design:** На малом экране фото/действие в строке над названием; начиная со sm сохраняется текущая компоновка. Общие данные на телефоне показывают подпись над значением, на широком экране остаются парами. Данные, порядок вкладок, формы и права не меняются.
