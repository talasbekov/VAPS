# UX/UI до утра: план выполнения

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Implementation is inline; a fresh reviewer checks the changes before completion.

**Goal:** Улучшать подтверждённые неудобства Smart Josparlau автономно до 10:00 13 октября и оставить проверенный локальный портал.

**Architecture:** Существующие React-экраны и серверные контракты сохраняются. Каждая правка ограничивается воспроизведённым сценарием; данные записи изолированы от основной базы.

**Tech Stack:** Next.js 15, React 19, TypeScript, react-hook-form, Zod, Playwright, Django/PostgreSQL; Windows Chromium с Direct3D11.

**Spec:** [UX до утра](../specs/2026-10-12-overnight-ux-design.md).

## Global Constraints

- Основные бизнес-данные не менять. Записи и полный пользовательский цикл проверять только в отдельной базе.
- Сохранять имеющиеся права, области доступа, импортированные ID и незаполненные даты.
- Не удалять накопленные кэши, видео, копии баз и доказательства проверок.
- Не публиковать и не отправлять изменения в удалённые репозитории в рамках этой задачи.
- Офлайн-карта и её поиск не должны обращаться к внешним сервисам.
- Перед утверждением готовности выполнить `npm run gate:front`; перечисление browser-тестов не считать их выполнением.

## Review Focus

- Смена срочного статуса на «В строю» при уже введённом неверном периоде: скрытые даты не препятствуют сохранению.
- Незагруженные сведения о выбранных сотрудниках: форма не обещает готовность.
- Право чтения без права изменения: навигация и просмотр доступны, бизнес-записи закрыты.
- Повторные переходы между картой, структурой и обычными страницами: тяжёлые ресурсы освобождаются после закрытия.
- Ошибка сети при сохранении: пользователь сохраняет черновик и видит понятный способ повторить действие.
