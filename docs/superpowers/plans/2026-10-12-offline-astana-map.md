# Offline Astana Map Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. The user delegated autonomous implementation.

**Goal:** Выбирать объекты и наружные посты на настоящей полностью офлайн-карте Астаны.

**Architecture:** Локальные OSM-геометрии и Canvas 2D; позиции — данные посещения и поста; существующие выборы URL и правила расстановки.

**Tech Stack:** Python/pyosmium для подготовки, TypeScript/Canvas/React для отображения, Django/PostgreSQL для прав/блокировки, приватный GeoJSON для позиций.

**Spec:** `docs/superpowers/specs/2026-10-12-offline-astana-map.md`

## Global Constraints

- Нет внешних запросов карты, CDN, WebGL и геокодирования при работе приложения.
- Схема действующей базы не меняется; GeoJSON и реальные записи проверяются на собственной изолированной копии.
- Фиктивные точки запрещены; незаданные координаты явно обозначаются.
- Сохранение места не изменяет потребность, людей или назначение поста объекту.
- Права, стадии и заморозка те же, что у соответствующего объекта расстановки.

## Review Focus

- Чужой визит/пост и сотрудник вне области права не могут изменить место.
- Пустые, NaN, бесконечные и неполные координаты не принимаются.
- Ошибка API не превращается в успешное сохранение; выбор места можно отменить.
- Несколько объектов, пост без объекта, точка вне области карты сохраняют понятный список и корректный URL.
- Отключённая сеть, смена размера и повторное открытие карты не теряют подложку и не создают постоянную анимацию.
