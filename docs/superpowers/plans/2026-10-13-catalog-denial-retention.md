# Сохранение отказа доступа в двух каталогах

**Goal:** Каталоги охраняемых лиц и нормативной базы не раскрывают прежние карточки после401/403/404→retry503; успешное фактическое чтение восстанавливает доступ без открытия старой формы.

**Design:** Повторно использовать проверенный Query identity/AbortSignal read guard. Hooks каталога возвращают readAccessBlocked; существующие availability/page guards скрывают данные и закрывают editor/history/disclosure до успешного GET. Существующие права, временное сохранение черновика при обычном503, payload и backend не меняются. Другие потребители hook не расширяют область этого этапа.
