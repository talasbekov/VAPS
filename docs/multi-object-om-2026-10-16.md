# ОМ на нескольких объектах — 16 октября 2026

## Результат

Одно мероприятие ведётся на нескольких площадках. В сборе сил виден весь маршрут и отдельный расчёт по каждой готовой площадке: потребность, назначенные, недобор. Список показывается до поступления сотрудников. Объект с незавершённой рекогносцировкой виден с пояснением, но недоступен для распределения.

Название ОМ и свободная область строки реестра открывают мероприятие; название площадки открывает её рабочий контекст внутри ОМ. Подробности раскрываются отдельной кнопкой 44×44. В сборе название открывает карточку сбора, рядом есть подписанное действие «Открыть сбор».

В карточке мероприятия все объекты переключаются крупными кнопками, несколько новых объектов добавляются существующим диалогом. Паспорт выбранного объекта открывается отдельной явно подписанной ссылкой. Прежняя ссылка на основной объект скрыта при наличии канонических объектов посещения. Поле основного объекта многоплощадочного бюллетеня теперь подписано соответственно.

После передачи наряда позднее пополнение можно распределить, сохраняя блокировку уже назначенных сотрудников. Для сбора без объектов передача состава не требует невозможного выбора площадки.

## Контракт и права

Используются существующие `OpsSecurityEventVisitObject` и `visitObjectId`; новых таблиц и миграций нет. Необязательное поле `visitObjects` в списке/карточке сбора содержит весь маршрут, включая ещё не опубликованные площадки и исторические названия объектов с удалённой ссылкой каталога. Старое `objects` сохраняет прежние доступные для назначения цели и их серверную ёмкость. `null` потребности не превращается в ноль.

Одинаковые названия не объединяются: связи и отправка назначений используют канонический ID, на экране площадки различимы по порядку. Предзагрузка исключает новый запрос на каждую строку списка. Области доступа и правила публикации расчёта сохранены. Просмотр сбора сам по себе не даёт права открыть ОМ, паспорт или добавлять объекты. Редактирование бюллетеня также не выдаёт право управления площадками.
