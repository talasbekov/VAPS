# `common` — что осталось после сноса старой системы ролей

🔴 **Этот README описывал систему, которой больше нет.** До 31.08.2026 здесь
были шесть портальных ролей (`ROLE_1`…`ROLE_6`), таблица прав в БД, команда
`setup_demo_roles`, ручка `api/common/role-types/` и описание claims токена с
полями `is_admin`, `is_hr_admin`, `is_manager`. Всё перечисленное снято планом
№352 (Plane, шаги Ш-1…Ш-6): заказчик потребовал работать по семи своим ролям,
а они живут в каталоге раздела ОМ.

## Где теперь права

| Что | Где |
|---|---|
| Роли, права, назначения с областью у КАЖДОГО гранта | `apps/operations` — модели `Role`, `Permission`, `RolePermission`, `UserRole` |
| Проверка права и области | `apps/operations/services.py` — `PermissionService` |
| Что можно текущему запросу | `GET /api/operations/my-permissions/` |
| Раздача ролей | экран «Система → Роли» (`/settings/roles`), команда `seed_operations --assign` |
| Учётки под каждую роль раздела | `manage.py seed_role_accounts --password …` |
| Семь учёток заказчика под ручную проверку | `manage.py seed_access_matrix --password …` |

Один человек может иметь СКОЛЬКО УГОДНО ролей, у каждой своя область —
именно этого старая система и не умела: `UserRole` был `OneToOneField`.

## Что осталось в `common`

- `rbac.py` — перевод кадровых имён прав (`view_staffing_table`,
  `create_vacancy`, …) в коды раздела и расчёт области по гранту. Единственный
  мост между старыми точками вызова и новым каталогом.
- `drf_permissions.py` — `RoleBasedPermission` и классы прав штатки/вакансий
  поверх `rbac.check_permission`.
- `jwt_serializers.py` — токен говорит, КТО вошёл; о правах он не
  рассказывает (Ш-4), их спрашивают у ручки выше.
- `services/permissions.py` — область отчётов, считается по гранту
  `orgstructure.view`.
- `admin.py` — карточка пользователя с сотрудником; ролей в админке нет.
- `management/commands/` — `seed_access_matrix`, `seed_demo_all`.
- `models.py` — пуст: моделей у приложения больше нет.

## История

Зачем всё это делалось и в каком порядке — план №352 в vault
(`WIKI/План-352-Снос-старой-системы-ролей.md`) и записи `Decisions.md` за
31.08.2026: почему снос шёл последним шагом, а не первым, и почему читателей
снимали по одному.
