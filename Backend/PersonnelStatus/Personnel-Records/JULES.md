# Jules Instructions

Before any task in this repository:

1. Use Graphify first.
2. Check `graphify-out/graph.json`.
3. Do not start with broad grep/rg/find.
4. Use:
   - `graphify query "<question>"`
   - `graphify explain "<module/class/function>"`
   - `graphify path "<source>" "<target>"`

Graphify was generated with:

```bash
graphify extract --no-cluster .
```
