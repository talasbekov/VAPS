# Шрифты

**UI-портал:** системный sans-стек, внешние шрифты не подключаются (без изменений).

**Печать (стори 8.8):** вендоренный PT Serif — казахская кириллица для печатных
форм (юридический артефакт, канон architecture L255/L264: вендоринг в репозиторий,
внешние запросы за шрифтами запрещены — закрытый контур).

- Источник: `@fontsource/pt-serif@5.2.8` (одноразовый источник файлов, пакет
  в package.json НЕ живёт — Д5); имена файлов пакета сохранены.
- Состав: `pt-serif-{latin,cyrillic,cyrillic-ext}-{400,700}-normal.woff2`
  (казахские глифы Ә Ғ Қ Ң Ө Ү Һ — сабсет cyrillic-ext; Ұ І — cyrillic;
  цифры/латиница — latin).
- Лицензия: SIL OFL 1.1 — `LICENSE-PT-Serif.txt` (обязательна при редистрибуции).
- Подключение: ТОЛЬКО `@font-face` в `src/features/print-forms/print.css`
  (UI-слой это семейство не использует); `url(http…)` в css запрещены.
