# Спайк 3.13 — часы без NTP (рассинхрон/дрейф времени контура)

Одноразовый инфраструктурно-операционный спайк: систематизирует поведение
**временного ядра** при переводе/рассинхроне/**дрейфе** часов сервера контура,
который **не имеет публичного NTP** (architecture.md:57). Дисконтирует «самый
умный и самый непроверенный узел» (architecture.md:711) ДО пилота.

**Это НЕ код.** Спайк ничего не реализует — он ВЕРИФИЦИРУЕТ существующее и
ДОКУМЕНТИРУЕТ знание + процедуру админа:

- **Backward-перевод часов** (`today < watermark`) → catch-up **стоп + алерт**,
  данные целы — **уже реализовано в стори 3.12** (`apps/operations/statuses/services/catch_up.py`),
  доказано тестами (`test_catch_up.py::*halt*`). Спайк ссылается, не дублирует.
- **tzdata-канарейка** (`utcoffset(Asia/Qyzylorda)==+05:00`) → **уже в гейте**
  (`apps/core/tests/test_tzdata_canary.py`). Спайк её прогоняет (3 passed), не пересобирает.
- **Clock-сервис** (`apps/core/clock.py`) — единая точка чтения wall-clock. Не трогается.

## Содержимое

- [`FINDINGS.md`](./FINDINGS.md) — каталог 6 режимов рассинхрона × текущая
  обработка × **остаточный риск** × действие админа × стори-владелец; два главных
  риска (forward-jump ≤ sanity, постепенный дрейф) + таблица «находка → стори».
- [`RUNBOOK-clock.md`](./RUNBOOK-clock.md) — процедура админа контура: обнаружение
  дрейфа без NTP, безопасная коррекция, переравнивание `watermark`, DO/DON'T,
  верификация backward-halt.

## Два главных остаточных риска (ради чего спайк)

1. **Прыжок вперёд ≤ sanity (366 дн.)** — 3.12 sanity-потолок ловит лишь абсурд
   (`gap > 366`); forward-прыжок «+N дней» (N≤366) → материализует до **N** «будущих»
   дней (`MAX_CATCHUP_DAYS=31`/**прогон**, за несколько прогонов — watermark двигается,
   следующий прогон продолжает) + `business_date` расхода/дедлайна 17:00 неверна.
   **`--today`-гард это НЕ кроет** (он про ручной CLI-аргумент; beat берёт
   `Clock.today_local()`) → forward-bound-guard в будущей стори.
2. **Постепенный дрейф без NTP** (главный реальный режим) → midnight-сдвиг
   `business_date` → расход/17:00 за неверный день. → drift-монитор (E12) + ручная
   сверка (рунбук).

Кода для этих гардов спайк **не строит** — это находки для будущих стори
(анти-gold-plating). Контур без NTP — by design, не недостача.
