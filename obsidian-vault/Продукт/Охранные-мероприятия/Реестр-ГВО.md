# Реестр ГВО

> В сайдбаре прототипа отсутствует; модуль существует в коде.

## Назначение
Реестр мероприятий с участием главы и высших охраняемых лиц (ГВО): сводки по мероприятиям с данными о прибытии и охраняемых лицах.

## Маршрут и доступ
`/security-ops/gvo` (карточка сводки — `/security-ops/gvo/[id]`); права проверяет страница (use-ops-permissions).

## Экраны и флоу
Из кода (прототипа для модуля нет):
- Список «Реестр ГВО» (группа «Оперативная работа») с категориями мероприятий и признаком заполненности сводки («Заполнена» / «Черновик сводки»).
- Карточка сводки: блоки «Сводные данные», «Охраняемые лица», «Прибытие / тип борта».

## Данные и API
Живой бэк с 20.08.2026: `GET/PATCH /api/ops/gvo-summaries/` + `POST …/reset/` (хранение ручных правок сводки, модель `OpsGvoSummaryPatch`, один патч на мероприятие); база сводки по-прежнему собирается на клиенте из бюллетеня. Права: чтение `event.view`, правка `event.manage`. Мок MSW остаётся для демо через `NEXT_PUBLIC_OPS_MOCK_DOMAINS=gvo`.

## Ограничения и расхождения
- Записи ГВО = проекция мероприятий; связь «лицо → ОМ» существует только через сводки ГВО.
