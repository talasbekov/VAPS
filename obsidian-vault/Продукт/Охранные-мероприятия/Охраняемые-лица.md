# Охраняемые лица

> В сайдбаре прототипа отсутствует; модуль существует в коде.

## Назначение
Профили лиц, в отношении которых организуются охранные мероприятия.

## Маршрут и доступ
`/security-ops/persons`; права проверяет страница (use-ops-permissions).

## Экраны и флоу
Из кода: страница «Охраняемые лица» (группа «Оперативная работа») — реестр профилей лиц; подзаголовок в коде: «Профили лиц, в отношении которых организуются охранные мероприятия».

## Данные и API
Живой бэк с 20.08.2026: `GET /api/ops/protected-persons/` (модель `OpsProtectedPerson`, каталог правится через Django Admin, сид `seed_protected_persons`). Право: `event.view`. Мок MSW остаётся для демо через `NEXT_PUBLIC_OPS_MOCK_DOMAINS=protected-persons`.

## Ограничения и расхождения
- Связь «лицо → ОМ» существует только через сводки ГВО (см. [[Реестр-ГВО|Реестр ГВО]]), собственного хранилища связей у модуля нет.
