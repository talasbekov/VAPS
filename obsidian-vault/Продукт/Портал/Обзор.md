# Обзор

> В прототипе Smart Жоспарлау этот модуль объединён с тремя другими как «Сотрудники и штат».

## Назначение
Главный дашборд портала «Проект Расход»: сводные показатели по личному составу, статус подразделений и лента последних действий. Точка входа после логина.

## Маршрут и доступ
`/dashboard`; право: resource=organization, action=read (свой ресурс `dashboard` не заведён — пункт сайдбара «Обзор» гейтится правом на организацию).

## Экраны и флоу
- Карточки показателей (`StatsCards`) и виджет `status-overview` — распределение сотрудников по статусам.
- Доска подразделений (`OrgBoard` из `features/organization-structure`) с выбором департамента.
- «Последние действия» — 4 записи журнала аудита с цветовой точкой по глаголу события (создание — зелёная, снятие/отмена — оранжевая, остальное — синяя).
- Блок недоступных метрик прототипа («Эффективность обновления», «Время ответа», «Точность данных») — показываются словами с причиной, почему система их не считает; постоянные числа-заглушки удалены.
- Часы «последнее обновление» рендерятся только после маунта (иначе hydration mismatch).

## Данные и API
- `/api/statuses/statuses/absence_statistics/` — статистика отсутствий (app `statuses`).
- `/api/operations/audit-logs/?limit=4` — лента последних действий (app `operations`).
- Данные по структуре — через фичу `organization-structure` (apps `divisions`, `staff_unit`).

## Ограничения и расхождения
- «Последние действия» берутся из `/api/operations/audit-logs/` — журнала раздела ОМ, а не отдельного аудита портала.
- KPI прототипа (87/92/94) сознательно не считаются — вместо чисел объяснение причины (приём `unavailableKpi` бэка).
- Права: используется ресурс `organization`, отдельного права на дашборд нет.
