# Управление персоналом

## Назначение
Реестр сотрудников своего управления: поиск, фильтрация, карточки и профиль сотрудника, добавление нового сотрудника.

## Маршрут и доступ
`/employees`; право: resource=employees, action=read. Область видимости — своё управление (`DirectorateAccessNotice` при отказе); добавление — за `PermissionGate`.

## Экраны и флоу
- Карточки статистики (`StatCard`) по списку.
- Три вкладки: «Список сотрудников» (`EmployeeTable`), «Карточки», «Профиль сотрудника» (`EmployeeProfile`, появляется при выборе сотрудника).
- Поиск и фильтры по подразделению и статусу; отбор живёт в АДРЕСЕ (query-параметры `search`/`department`/`status`), умолчания в URL не пишутся — ссылкой на отфильтрованный список можно поделиться.
- Диалог добавления сотрудника (`features/add-employee`).
- Обновление списка вручную (инвалидация react-query).

## Данные и API
- `/api/staff_unit/staff-units/directorate/` — штатные единицы с сотрудниками и текущими статусами (та же ручка, что у [[Статусы-сотрудников|Статусов сотрудников]]; apps `staff_unit`, `employees`).
- Маппинг персональных полей — `entities/employee/model/from-api` (`personnelFields`); документы сотрудника — app `documents`.
- Словарь статусов для фильтра — `lib/status` (`EMPLOYEE_STATUS_*`).

## Ограничения и расхождения
- В прототипе Smart Жоспарлау аналога нет — модуль за рамками прототипного «Сотрудники и штат».
- Список читается через `staff_unit`-ручку, а не через прямой `/api/employees/` — сотрудник виден в связке со штатной единицей.
