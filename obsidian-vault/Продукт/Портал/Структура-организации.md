# Структура организации

> В прототипе Smart Жоспарлау этот модуль объединён с тремя другими как «Сотрудники и штат».

## Назначение
Организационная схема и сводка укомплектованности: штат, занятые единицы и вакансии по трём уровням иерархии (департамент → управление → отдел).

## Маршрут и доступ
`/organization`; право: resource=organization, action=read.

## Экраны и флоу
- Оргсхема (`OrgChart` из `features/organization-structure`).
- Карточки сводки (`StatCard`) по summary статистики штатных единиц.
- Таблица «в разрезе»: три массива ручки (departments / directorates / divisions) сведены в один плоский список строк сверху вниз по уровням — колонки «Подразделение, Уровень, Штат, Занято, Вакансий».
- Кнопка выгрузки CSV: собирается на клиенте из показанных строк, с BOM (иначе Excel читает кириллицу как мусор).

## Данные и API
- `/api/staff_unit/statistics/` — сводная статистика штатных единиц (app `staff_unit`).
- Оргсхема — данные фичи `organization-structure` (apps `divisions`, `staff_unit`).

## Ограничения и расхождения
- Отдельной серверной ручки выгрузки структуры нет — CSV формируется из того, что показано на экране.
