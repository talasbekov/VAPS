# Отчеты

> В прототипе Smart Жоспарлау этот модуль объединён с тремя другими как «Сотрудники и штат».

## Назначение
Генерация и скачивание официальных документов по сотрудникам и статусам. Живой отчёт один — «Расход Л/С» (строевая записка); остальные карточки — заглушки «В работе».

## Маршрут и доступ
`/reports`; право: resource=reports, action=read.

## Экраны и флоу
- Карточка «Расход Л/С»: выбор даты в календаре → «Показать расход» → таблица строевой записки по своей области видимости; выгрузка Excel — по строке подразделения (флаг «занято» держится на строке, не на карточке).
- Выгрузка доступна только по СДАННОМУ дню — на несданном сервер законно отказывает (тост «День не сдан»).
- Три карточки-заглушки с бейджем «В работе» и задизейбленными кнопками: «Статистика отсутствий», «Штатное расписание», «Журнал действий».

## Данные и API
- `/api/operations/strength-report/` — чтение живого расхода; `division_id` намеренно не передаётся — бэк сам сужает выборку по области видимости (app `operations`).
- `/api/operations/strength-report/export/` — выгрузка по подразделению.
- Legacy-ручка `/api/reports/reports/expense/<department_id>/` (app `reports`) в клиенте описана, но живой экран ходит в `operations`.

## Ограничения и расхождения
- Фактический бэк модуля — app `operations` (strength-report), а не app `reports`, вопреки названию модуля.
- Три из четырёх отчётов — нереализованные заглушки.
- Название модуля в сайдбаре — «Отчеты» (без «ё»), в отличие от «Отчёты службы» в разделе ОМ.
