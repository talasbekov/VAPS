# Backlog — непроверенное

Сюда попадает то, что есть только в одном из источников (прототип ИЛИ код) либо ни в одном, и потому в основную документацию не включается. Каждая запись — кандидат на решение заказчика/разработчика, не обязательство.

## Из прототипа, но нет в коде

- **Экран «План дежурств»** (`Дежурства.dc.html`: план на объект/год/месяц, статус DRAFT, справочник видов дежурств, схема объекта с постами). Страница `/security-ops/duties` удалена из кода 13.08.2026; замены на посту живут в [[Охранные-мероприятия/Календарь-смен|Календаре смен]], боевой расчёт — в [[Охранные-мероприятия/Боевые-группы|Боевых группах]]. Если экран нужен — это возврат фичи, не документация.
- **Охраняемые лица в карточке ОМ** — прототип показывает лиц, старшего ГВО, численность и количество охраняемых; бэк этих полей не хранит (UI даёт прочерк). Связь «лицо → ОМ» сейчас есть только через сводки ГВО на моке.
- **Светофор «сдано, но разошлось»** — третье состояние индикатора сдачи (drift) заявлено в архитектурных решениях BMAD, но как пользователь его видит — не определено ни в прототипе, ни в коде.

## Из кода, но без пользовательского сценария

- **Амендмент-флоу ретро-правок расхода** (версионируемая сдача, взамен-нумерация) — модель описана в архивной архитектуре BMAD, UI-сценария нет ни в прототипе, ни в коде.

## Открытые вопросы контрактов

- **Формат кодов прав ops.**: фронт запрашивает `ops.<resource>.<action>`, сиды бэка исторически генерировали коды без префикса. Зафиксировано в [[../Frontend/Known-Issues|Frontend/Known-Issues]]; требует сверки с живыми сидами перед новой работой по RBAC.
- **Конвенция ID в `/api/ops/*`**: контракт фронта объявлял string, бэк отдаёт int — унификация не оформлена решением.
