## Тулинг и скиллы

Personal-скиллы ставятся `npx skills add` в `/home/erda/.agents/skills/<name>`, симлинкуются в `/home/erda/.claude/skills/<name>`. Список слэш-команд строится при старте сессии — скилл, поставленный в уже открытую сессию, невидим до перезапуска; «isn't a recognized command here» не значит «не установлен», проверять `ls`/`head SKILL.md` напрямую. У personal-скилла (в отличие от плагина) `CLAUDE_PLUGIN_ROOT` пустой — пути к скриптам в SKILL.md писать абсолютными, не через переменную.

`npx skills find` в этой песочнице виснет насмерть (реестр недоступен через прокси), но `npx skills add <owner/repo>` работает нормально (другой путь). Искать скиллы вместо CLI через `WebFetch` по `skills.sh` (лидерборд, `/topic/<slug>` в единственном числе, карточка `skills.sh/<owner>/<repo>` с install count).
