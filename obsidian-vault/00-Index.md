Активное: [[WIKI/Разбор-очереди-Plane|разбор очереди Plane]] (как хаотичный ввод заказчика становится порядком работы — читать перед взятием задачи; срез 24.08: 10 открытых) · [[WIKI/План-217-Роли-наряда-в-расстановке|план №217: роли наряда]] · [[WIKI/План-225-Реестр-под-5000-сотрудников|план №225: реестр под 5000]] · [[WIKI/План-198-Тестовые-данные-и-админка|план №198: тестовые данные и админка]] · [[WIKI/Бэклог-Smart-Josparlau|бэклог Smart Josparlau]] (история переноса из ClickUp) · [[WIKI/Хендофф-2026-08-21|хендофф на следующую сессию]] (закрытые журналы смен и отчёты сверок уезжают в [[Archive/README|Archive/sessions]])

- [[RAW/README|RAW]] — сырые материалы: транскрипты, статьи, черновики, веб-клипы. Архив источников, не переписывается.
- [[WIKI/README|WIKI]] — структурированные заметки: исследования, планы/эпики, знания без своего раздела. Связывать `[[ссылками]]`, без сирот.
- [[OUTPUT/README|OUTPUT]] — готовые документы для внешнего использования.
- [[LOG|LOG]] — журнал обработки: `- [YYYY-MM-DD HH:MM] что сделано`.

Цикл: новое сырьё в `RAW/` → выделить ключевое → создать/обновить заметки в `WIKI/` → обновить этот индекс → запись в `LOG.md`. Подробные правила — в README каждой папки.
