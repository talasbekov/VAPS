Обе матрицы описывают **демонтированную SPA** (`frontend/`); актуальное на 19.08 состояние — внизу. См. ## Чем гонялись тесты (SPA, история)

- **Гейт**: `npm run gate` = deps-gate, schema-check, `tsc -b`, eslint (boundaries + print-canon), `vitest run`, production `vite build` + size-gate (бюджет 300 KB gzip). Baseline Этапа 0 (2026-07-23): 790 тестов, 178.5 KB; на Этапе 53 — 1682 теста, 264.8 KB.
- **Unit/integration**: vitest — repository-тесты каждой фичи (permission-check 403, валидация 422/409, персистентность «из БД, не из памяти вызова»), контрактный тест demo-снапшота в `app/` (все узкие проекции против реального сида — типы границу фич не защищают).
- **E2E mock**: Playwright `e2e-mock/` против `build:mock` (реальный chromium, IndexedDB) — свой конфиг/порт 4176, дорос до 94 спек-прогонов; каждый реализованный экран покрыт.
- **E2E live (донор)**: `npm run test:e2e` — 62-63 теста, отдельный конфиг, при срезах не задевался.
- Методика: **красная проба обязательна** для каждого важного ассерта (мутировать код → тест обязан покраснеть; зелёная проба = вакуумный ассерт); детерминизм e2e проверялся двойным прогоном подряд.

## Что покрыто

Все Verified-экраны матрицы прослеживаемости (см. [[Архитектура-SPA|Архитектура (SPA)]]): жизненный цикл ОМ целиком, §24-конвейер боевых групп от потребности до сдачи смены, дежурства (план/месяц/карточка/правка), объекты и версии паспортов, sensitive identity §20, отчёты §22, обратная связь §28, настройки §29 (зеркальные права по разделам), рейтинг §19, справочники §30, печатная форма расстановки (парсер физически не разбирает закрытые поля — §19.24). Route audit: карта гейтов всех маршрутов (без права → «Доступ запрещён»). Accessibility: 4 слоя (ручной проход, клавиатурные вкладки, axe-core с нулём находок, skip-to-content).

## Известные ямы прогонов

- E2E регулярно находил реальные дефекты, недостижимые unit-уровнем: MSW-коллизия путей (`acknowledgement/complete` матчился как `:assignmentId`), `target="_blank"` терял sessionStorage-credential, label без htmlFor, DemoToolbar перекрывал кнопки.
- Глобальный реестр модуля (RBAC-директория, MSW, часы) + `beforeEach` в новом describe роняет чужие тесты — прогонять весь файл, не свой блок.
- `SCHEMA_VERSION` compose-seed бампается при каждом изменении формы слайса — иначе старый IndexedDB молча ломает страницы.
- Смотреть `grep failed/✘`, не `tail` — хвост репортёра прячет падения.
- Флейк донора `DailyUpdatePage.test.tsx` блокировал одношаговый gate (вне scope Smart Josparlau).
