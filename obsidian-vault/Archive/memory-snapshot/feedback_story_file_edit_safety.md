Инцидент dev-story 8.4 (2026-07-07): python-скрипт простановки чекбоксов через
`str.partition` (перепутан сепаратор и хвост) обрезал стори-файл после «## Tasks /
Subtasks». Файл был untracked (стори-цикл коммитится после ревью — [[bmad-story-cycle-flow]]),
git-копии не было; восстановлен только потому, что был прочитан целиком в контекст ранее.

**Why:** стори-файлы между create-story и коммитом ревью существуют в единственном
экземпляре на диске; любая скриптовая правка со сборкой строки — риск тихой потери.

**How to apply:** чекбоксы и статус в стори-файлах менять точечными Edit (old→new)
или sed по одной строке; если всё же скрипт — сначала копия в scratchpad; всегда
читать файл целиком до правок (это и есть страховка восстановления).
