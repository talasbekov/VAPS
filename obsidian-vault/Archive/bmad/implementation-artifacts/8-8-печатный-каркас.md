## Story

As a оператор,
I want отдельный print-route (`/print/test`) с голым семантическим HTML и собственным `print.css` (вендоренный PT Serif с казахской кириллицей, типографика печатного контракта 16/12/8 pt), на который не влияет ни один класс UI-слоя (shadcn/Tailwind),

### Ловушки

1. **ГЛАВНАЯ — print.css попадает в ОБЩИЙ бандл SPA:** Vite конкатенирует CSS всех статических импортов в один файл; элементный селектор без скоупа (`h1 { font-size: 16pt }`) отравит типографику ВСЕГО портала. Всё — строго под `.print-root`; глобальны только `@font-face` (безопасны: применяются лишь там, где указано семейство) и `@page`/`@media`-обёртки. Негативный контроль — e2e-ассерт (д) на `/login`.
2. **Tailwind preflight действует и на print-роуте** (index.css глобален, роут — часть SPA): preflight обнуляет размеры заголовков, margin, границы таблиц — «голый HTML» без print.css выглядит НЕ как браузерный дефолт. print.css обязан задать печатный контракт ПОЛНОСТЬЮ (шрифт/размеры/отступы/границы), не полагаясь ни на дефолты, ни на preflight.
3. **`@page size` не поддержан FF100** (появился в FF110): ориентацию landscape в контуре оператор выбирает в диалоге печати; `size` в print.css — прогрессивное улучшение (Chromium-смок его видит). В инструкциях/тексте страницы на `@page size` НЕ полагаться. `eslint-plugin-compat` CSS не проверяет — дисциплина + комментарий в css.
4. **Chromium-смок ≠ FF100-печать:** канон L260 — Playwright на FF100 невозможен. Смок доказывает: изоляцию классов, загрузку вендоренных глифов, скрытие screen-hint, отсутствие утечки скоупа. Пиксельная верность печати на целевом браузере — ручной релизный смоук (путь уже принят в 8.7/спайке 1.10, deferred-work L96).
5. **`no-custom-classname` покраснеет на `print-root` без whitelist** — добавлять whitelist ТОЛЬКО override-блоком для `src/features/print-forms/**` (flat config: последний матчащий блок побеждает по settings). Глобальный whitelist ослабил бы канон ARCH-FE-014 для всего src — НЕ делать.
6. **Сид credential в e2e — только `addInitScript`** (исполняется ДО скриптов страницы): `page.evaluate` после load опоздает — RequireAuth уже средиректит на `/login` (credential-store гидратируется на init модуля, `credential.ts` L59). Ключ — `vaps.credential`, sessionStorage (per-tab; формат `{ kind: 'dev', userId: string }`).
