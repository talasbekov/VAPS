## Story

As a **руководитель**,
I want **по корню поддерева получить каскадный светофор: per-division состояние (5.5a) свёрнутое ВВЕРХ одним обходом дерева правилом «худший цвет» (RED > YELLOW > GREEN), с видимой `late`-меткой**,
so that **на дереве подразделений видно и отставание (RED где-то внизу), и drift после сдачи (YELLOW), агрегированные к каждому узлу — фундамент светофор-дерева 10.4, считается bulk-запросами без N+1 (NFR-4)**.

## Acceptance Criteria

1. **Каскад вверх одним обходом.** **Given** корень поддерева и `business_date`, **When** вызываю `traffic_light_tree(root_division_id, business_date)`, **Then** возвращается состояние per-division для КАЖДОГО узла поддерева (`subtree_ids`), где состояние узла = свёрнутое ВВЕРХ: `cascade(node) = worst_colour(own(node), *[cascade(child) …])`. Обход — ОДИН проход (post-order) по `CoreDivisionTreeSelector` (ARCH-DATA-024 — единственный канал), НЕ `subtree_ids`/`roster_on`/`current_for` на узел. [Source: epics.md 5.5 «каскад агрегируется вверх одним селектором обхода дерева»; architecture.md ARCH-DATA-024]
2. **Worst-colour precedence.** **Given** узел со своими и/или дочерними состояниями, **Then** цвет узла = худший по precedence **UNKNOWN > RED > YELLOW > GREEN**; `NEUTRAL` (узлу нечего сдавать) — нейтральный элемент (не влияет; узел без не-нейтральных вкладчиков → `NEUTRAL`). [Source: 5.5 каскад; реш. №1]
3. **own-state узла (реюз 5.5a-логики, bulk).** **Given** дивизион D, **Then** own(D): нет действующей сдачи + НЕпустой own-ростер → `RED`; нет сдачи + пустой own-ростер → `NEUTRAL` (закрывает Q3-дефер 5.5a — neutral отдан каскаду); есть сдача → `_diff_winners(_snapshot_winners(sub.snapshot), live_winners[D])` → пусто `GREEN` иначе `YELLOW`; `late` берётся со сдачи. own-state D БАЙТ-В-БАЙТ совпадает с `division_traffic_light(D, date)` 5.5a для листа. [Source: 5-5a; реш. №2/№3]
4. **late видим в каскаде.** **Given** хоть одна поздняя сдача в поддереве узла, **Then** свёрнутое состояние узла несёт `late=True` (OR по поддереву). [Source: epics.md 5.5 «late видим в каскаде»]
5. **Bulk — без N+1 (NFR-4).** **Given** поддерево из N дивизионов, **Then** РОВНО: один `subtree_ids`/`children_map` (один FULL-scan Division), один `roster_on(date, subtree)`, один `overlapping_on(date, все_emp)`, один `current_for_many(subtree, date)`; `resolve_status` — раз на сотрудника (не на дивизион); НИ ОДНОГО запроса в цикле по узлам. [Source: architecture.md NFR-4 / bulk-селекторы; `StrengthReportService.compute` образец]
6. **D1 — изоляция битого узла.** **Given** дивизион, чей снапшот/live несёт `status_type_code` вне `STATUS_TYPE_PRIORITIES` (derive бросает `ValueError`), **Then** ЭТОТ узел → `UNKNOWN` (per-node try/except), остальной обход и fold НЕ падают; родитель свёртывает `UNKNOWN` по precedence. [Source: deferred-work.md D1 от 5.5a code-review]
7. **Bulk-селектор сдач.** **Given** набор дивизионов, **Then** `DailySubmissionSelector.current_for_many(division_ids, business_date)` → `{division_id: DailySubmission}` действующих (`is_current=True`) сдач ОДНИМ запросом (`division_id__in`); дивизион без сдачи отсутствует в map. ### 🔑 Решения по реализации (ДЕФОЛТЫ — подтвердить/переопределить; вопросы в конце)

1. **Worst-colour precedence UNKNOWN > RED > YELLOW > GREEN; NEUTRAL — нейтраль [ДЕФОЛТ].** Узел свёртывает own + детей; худший побеждает. NEUTRAL (нечего сдавать) не участвует; узел без не-нейтральных вкладчиков → NEUTRAL. *Почему UNKNOWN наверху:* битый/непосчитанный узел не должен маскироваться зелёным — «не знаю» честнее «всё ок». *Вопрос Q1.*
2. **NEUTRAL = пустой own-ростер + нет сдачи [ДЕФОЛТ — закрывает Q3-дефер 5.5a].** Чистый организационный узел без людей и без своей сдачи не красится RED (иначе всё дерево RED). Лист с людьми без сдачи → RED (как 5.5a). *Вопрос Q2.*
3. **own-state — реюз `_snapshot_winners`/`_diff_winners`/`current_for_many`, НЕ цикл `division_traffic_light` [ДЕФОЛТ].** Bulk-данные → те же pure-helpers per-division → own-state БАЙТ-в-БАЙТ как 5.5a для листа (тест-консистентность). 5.5a `division_traffic_light` остаётся single-division entrypoint (API 5.8 одного дивизиона), НЕ трогается.
4. **Возврат — flat `{division_id: CascadeTrafficLight(status, late)}` по ВСЕМ узлам поддерева (свёрнутый цвет) [ДЕФОЛТ].** Drift-детали (added/removed/changed) НЕ в каскаде — они per-division в 5.5a `division_traffic_light` (drill-down по клику). 10.4 берёт структуру из `CoreDivisionTreeSelector`, цвета — из этого map. *Вопрос Q3 (нужен ли own-цвет узла рядом со свёрнутым?).*
5. **D1-изоляция — per-node try/except ValueError → UNKNOWN [ДЕФОЛТ, из дефера 5.5a code-review].** Битый `status_type_code` в одном дивизионе → UNKNOWN-узел, fold живёт. Альтернатива (data-integrity guard StatusType⊆литерал на seed) — отдельный кросс-срезный вопрос, не здесь.

```python
# дополнение к apps/operations/submissions/traffic_light.py
_PRECEDENCE = {  # worst-colour
    TrafficLightStatus.NEUTRAL: 0, TrafficLightStatus.GREEN: 1,
    TrafficLightStatus.YELLOW: 2, TrafficLightStatus.RED: 3,
    TrafficLightStatus.UNKNOWN: 4,
}

def _worst(*statuses) -> str:
    return max(statuses, key=lambda s: _PRECEDENCE[s], default=TrafficLightStatus.NEUTRAL.value)

def _subtree_own_states(subtree, business_date) -> dict:
    roster = HistoricalEmployeeSelector.roster_on(business_date, subtree)         # 1 query
    all_emp = [e for emps in roster.values() for e in emps]
    rows = EmployeeStatusSelector.overlapping_on(business_date, all_emp)          # 1 query
    by_emp = {}
    for r in rows:
        by_emp.setdefault(str(r["employee_id"]), []).append(r)
    subs = DailySubmissionSelector.current_for_many(subtree, business_date)       # 1 query
    own = {}
    for div in subtree:
        members = roster.get(div, [])
        sub = subs.get(div)
        if sub is None:
            own[div] = (TrafficLightStatus.RED.value if members else TrafficLightStatus.NEUTRAL.value, False)
            continue
        try:
            live = {str(e): resolve_status(by_emp.get(str(e), []), business_date) for e in members}
            drift = _diff_winners(_snapshot_winners(sub.snapshot, business_date), live)
            own[div] = (TrafficLightStatus.GREEN.value if drift is None else TrafficLightStatus.YELLOW.value, sub.late)
        except ValueError:                                                       # D1 isolation
            own[div] = (TrafficLightStatus.UNKNOWN.value, sub.late)
    return own

def traffic_light_tree(root_division_id, business_date) -> dict:
    root = uuid.UUID(str(root_division_id))
    children = CoreDivisionTreeSelector.children_map()                            # 1 query
    subtree = CoreDivisionTreeSelector.subtree_ids(root)                          # reuses children source
    own = _subtree_own_states(subtree, business_date)
    result = {}
    def fold(node):                       # memoised post-order
        if node in result: return result[node]
        kids = [c for c in children.get(node, []) if c in subtree]
        kid_states = [fold(c) for c in kids]
        status = _worst(own[node][0], *[s for s, _ in kid_states])
        late = own[node][1] or any(la for _, la in kid_states)
        result[node] = (status, late)
        return result[node]
    for node in subtree: fold(node)
    return {div: CascadeTrafficLight(status=s, late=la) for div, (s, la) in result.items()}
```
