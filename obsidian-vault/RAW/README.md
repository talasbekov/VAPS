# RAW — сырые материалы

Сюда попадает всё необработанное: статьи, транскрипты встреч и созвонов, черновики,
клипы из веба (сюда же смотрит Web Clipper), скриншоты-заметки, требования «со слов»,
выгрузки переписок.

## Правила

- **Ничего не удалять.** Это архив источников. После обработки материал не переносится
  и не переписывается — на него ссылаются из `WIKI/`.
- Один файл — один источник (одна встреча, одна статья, один черновик).
- Имя файла: дата + короткий заголовок, например `2026-08-20 Созвон по аккредитации.md`.
  Для материалов без даты — просто человекочитаемый заголовок.
- В начале файла, если известно: откуда материал, дата, участники/автор.
- Обработанный материал помечается строкой `Обработано: [[имя заметки в WIKI]]` в шапке —
  так видно, что уже разобрано, а что ещё нет.
