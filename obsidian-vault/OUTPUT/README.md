# OUTPUT — готовые результаты

Документы «на выход»: отчёты, планы, презентации, ТЗ и спецификации для внешнего
использования, письма/записки для заинтересованных сторон.

## Правила

- Файл здесь — законченный артефакт, а не рабочая заметка. Черновики и рабочие
  материалы живут в `WIKI/` и `RAW/`.
- Имя: дата или версия + назначение, например `2026-08 Отчёт о состоянии VAPS.md`.
- Документ собирается из заметок `WIKI/` и разделов vault — в шапке полезно указать,
  из каких (`Источники: [[...]], [[...]]`), чтобы при обновлении знать, что пересобрать.
- Устаревшие версии не удалять — переносить в `Archive/` с пометкой даты.
