# План — реестр транспорта (ГОН), Plane №215

Решение заказчика 27.08.2026 по вопросу [[Бэклог-Smart-Josparlau|№170]]:
вариант «завести реестр транспорта». «План занятий» снят.

## Откуда берутся поля

НЕ из головы. Образец `docs/PersonnelStatus/04 Список броней в ГОН 05.91.2025 г. обнов.docx`
— одна таблица на 45 строк и 8 колонок, шапка «проект на 05.09.2025 г.»:

| Колонка образца | Поле модели |
|---|---|
| № п/п | порядковый номер строки документа, в модели не хранится |
| Марка автомобиля | `brand` |
| Классификация по кузову | `body_class` (в образце «седан (223)») |
| Год выпуска | `production_year` |
| ГРНЗ | `plate` |
| Класс брони | `armor_class` (в образце VR7) |
| Дислокация | `deployment` (в образце «Алматы», часто пусто) |
| Примечание | `note` (в образце «Автохозяйство») |

Владелец парка в шапке образца — РГП «Автохозяйство УДП РК»; отдельной
сущностью не заводится, пока парк один: выдуманная иерархия дороже, чем строка
в шапке документа.

## Что уже читает «транспорт» — найдено грепом ДО кода

- `apps/ops/gvo.py` — ключ `transport` сводки ГВО: список `{code, car}`,
  свободный текст, раздел патча `transport`.
- `apps/ops/documents_summary.py:277` — строки `transport_<n>` документа
  сводных данных склеиваются из тех же `code` и `car`.
- фронт: раздел «Транспорт» панели сводки ГВО.

Правило «расширять, не подменять»: свободный текст сводки ЖИВЁТ, пока его
читают эти двое. Выделение машины из реестра добавляется РЯДОМ, а снятие
старого источника — отдельным шагом после переезда читателей.

## Шаги

- Модель `OpsVehicle` и миграция
  - Поля по таблице выше, `is_active` для мягкого скрытия (удаление стёрло бы машину из истории мероприятий).
  - Уникальность ГРНЗ среди действующих: две машины с одним номером — это опечатка, а не парк.
  - Регистрация в админке Django с русскими подписями и отбором по классу брони.
- Сервис и API справочника транспорта
  - Список с отбором по классу брони, дислокации и признаку действующей.
  - Заведение, правка, деактивация — деактивация вместо удаления, как у охраняемых лиц.
  - Права: чтение — тем же правом, что справочники раздела ОМ; правка — правом настроек.
- Наполнение реестра демо-данными
  - Команда сида по образцу: марки, кузова, годы, ГРНЗ, классы брони, дислокация.
  - ГРНЗ ВЫДУМАННЫЕ: в образце стоят реальные номера, и класть их в репозиторий нельзя (тот же класс, что утечка позывных в №164).
- Экран справочника транспорта
  - Сначала скилл `/ui-ux-pro-max`, потом код — правка вида.
  - Таблица колонка в колонку с образцом, отбор, заведение и правка, состояния загрузки/пустоты/ошибки.
- Выделение транспорта на мероприятие
  - Связь ОМ ↔ автомобиль рядом со старым свободным текстом сводки ГВО.
  - Миграция с бэкфиллом не нужна: старые строки остаются свободным текстом и читаются прежним путём.
  - Сводка ГВО показывает выделенные машины реестра и текстовые строки вместе, различая их источник.
- Проба на весь путь
  - Красная проба: выделить машину на ОМ → она видна в сводке ГВО → снята с ОМ → исчезла.
  - Пин состава колонок реестра — подменить колонку, проба обязана покраснеть.
