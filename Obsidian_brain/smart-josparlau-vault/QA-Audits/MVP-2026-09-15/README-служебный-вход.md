# Безопасный вход

Исполнитель: Кодекс Астра 6.

Проверенный runtime — `playwright-cli` с интерактивными действиями `snapshot → fill → click → snapshot`, локальный URL `http://localhost:3108/`. Не использовать CUA page context для чтения локального защищённого файла: у него нет такого API.

## Последовательность

1. `playwright-cli open http://localhost:3108/`
2. `playwright-cli snapshot` и взять актуальные refs полей логина/пароля и кнопки.
3. Ввести логин: `playwright-cli --raw fill <login-ref> <логин>`.
4. Прочитать пароль только из утверждённого защищённого источника текущей сессии в переменную процесса и заполнить поле без вывода; имя файла и значение не записывать в заметки, команды, логи или межсессионные сообщения.

5. Нажать кнопку `Войти`, затем немедленно `playwright-cli snapshot` и зафиксировать URL, роль, меню и экран.
6. Для выхода — открыть «Меню пользователя», взять свежий ref `Выйти` из snapshot, нажать его и подтвердить возврат на форму входа.

`--raw` обязателен на шаге заполнения: он не печатает generated code со значением поля. Пароль не передавать через CUA, clipboard, командную строку с literal-значением, логи, артефакты или заметки.

## Учётки

Для учебных персон и технических ролевых учёток использовать только утверждённые защищённые источники, доступные текущей сессии. Перед сменой учётки всегда выйти из предыдущей. Автопрогоны не заменяют ручные click→observe-сценарии.
