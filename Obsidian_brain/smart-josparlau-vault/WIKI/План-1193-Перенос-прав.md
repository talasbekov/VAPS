# №1193 — перенос индивидуальных ролей и прав

Исполнитель: Кодекс Астра 6. Дата: 2026-09-11. Plane:618d2c66-cb4d-42b5-b18d-9231382599b4.

Цель: готовая локальная выгрузка и переносимый скрипт для закрытого Docker-сервера. Прямые уточнения заказчика: индивидуальный набор каждой учётки; подразделения исключены.

Архитектура: JSON без паролей и ФИО, точные логины, operations.Role/Permission/RolePermission и назначения; Django группы, индивидуальные разрешения и флаги staff/superuser/active. Области исходных назначений сворачиваются по роли с is_active=any в глобальные. Временные полномочия не переносятся: при действующих/будущих временных назначениях источник или адресаты отклоняются, чтобы не обещать точное совпадение. Сейчас таких записей у источника нет.

Применение через ctl.sh exec -T backend (существующий контейнер), без установки/пересборки. Пользователи сопоставляются по логину; отсутствующие не создаются, перечисляются в приватном отчёте. До записи полная проверка, резервный снимок прав, одна транзакция. У совпавших пользователей заменяются назначения, прямые Django-разрешения/группы/флаги; пароли не изменяются. Глобальные определения общих ролей и групп сверяются, конфликт с пользователями вне снимка блокирует изменение их прав. Повторный запуск без дублей.
