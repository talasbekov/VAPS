# Проверка справочников и автономный контур — план 19.09.2026

Исполнитель: Кодекс Астра 6.

> Исполнение: superpowers:executing-plans, последовательно в текущей сессии для группы справочников; LAN — следующая отдельная сессия по правилу №1107. Работа уже разрешена заказчиком, отдельное подтверждение обычных шагов не требуется.

**Goal:** проверить все справочники, исправить подтверждённые дефекты, показать реальные браузерные действия и подготовить воспроизводимый автономный комплект.
**Architecture:** существующая интеграция1c3c8050, Django Admin и действующие API; без новой модели данных и переноса реальной БД. Для проверок только учебные значения, для LAN чистая изолированная БД.
**Tech Stack:** Django/DRF/PostgreSQL, Next.js, Docker Compose, Linux x86_64.
**Spec:** поручение заказчика19.09.2026, записи [[../Infrastructure/Changelog]], карточки №1141/1278/1144.

## Ограничения

Постоянный runtime находится вне Codex worktrees. Реальные аккаунты/роли/назначения не изменяются. Архив семи справочников по решению27.08 не возвращается в активный API. Системные значения не создаются произвольно. Старую очередьMVP не продолжать. GitHub push ждёт отдельного разрешения после прежнего отказа автоматической проверки. On test/Done ставит заказчик.
