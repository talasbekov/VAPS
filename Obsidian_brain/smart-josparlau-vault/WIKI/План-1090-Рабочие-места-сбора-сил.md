> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

Исполнитель: Кодекс Астра 6. Дата: 2026-09-09. Plane: №1090, дизайн №1080.

**Goal:** Реализовать пять одобренных экранов с реальным обменом данными и доказанной сквозной работой ежедневного расхода и ОМ.

**Architecture:** Существующие scoped API и TanStack Query остаются источником данных. Новый ролевой вход отделяет ответственного и OPS_STAFF от legacy экрана; карточки сохраняют мутации и серверную валидацию. Расход агрегируется по управлениям без потери отделов и сотрудников.

**Tech Stack:** Next.js 15, React 19, TypeScript, TanStack Query, Django/DRF, PostgreSQL, Playwright/pytest.

**Spec:** [[../OUTPUT/Рабочие-места-ответственного-и-Штаба-Plane-1080]]. HTML-эталоны: `/home/erda/.codex/visualizations/2026/09/09/01a0854b-f163-7a83-a4f5-1c2163e9a144/*-v2.html`.

## Global Constraints

- Экран начальника управления не менять.
- Все количества, имена, даты, подразделения и состояния приходят с бэкенда; нет демонстрационных данных в production.
- Ответственный видит свой департамент; административный обзор ему недоступен. Штаб определяется ролью OPS_STAFF и правом forces.command.
- Управления раскрываются сразу до сотрудников; отделы не показывать, но их сотрудников и показатели учитывать.
- Различать запрошено, обещано, собрано и передано. Физический наряд и специальные группы учитывать отдельно.
- URL из уведомлений, серверные мутации, подтверждения недобора и блокировки отправленных версий сохранить.
- При ошибке запроса показывать ошибку с повтором, а не нулевые показатели; ожидание прав не раскрывает закрытый экран.
- Отсутствие явного статуса штатно означает выводимое «В строю»; показатель without_status информативен и не блокирует сдачу. Не красить этих людей как ошибку заполнения без отдельного серверного нарушения.
- В новом утверждённом макете ответственному доступно раскрытие несданного управления для контроля; его данные помечаются предварительными до сдачи. Сборка официального свода сохраняет серверные правила current submissions. Legacy DivisionGroup и экран начальника не менять.
- Внешний вид следует одобренным макетам, адаптируется к ширине, действия имеют доступные подписи.
- Текущий worktree: codex/1080-force-workspaces, база 64b7bfc7. Чужие незакоммиченные исправления №1082–1087 не переносить и не перезаписывать.
