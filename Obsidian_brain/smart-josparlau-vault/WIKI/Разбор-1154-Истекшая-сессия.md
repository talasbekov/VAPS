# Plane №1154 — отвергнутая сессия не возвращает форму входа

2026-09-10. Разрешённая группа №1139; карточка №1154 In Progress.
Исполнитель: Кодекс Астра 6.

## До исправления

Ведущий агент воспроизвёл в браузере: TTL access 60 секунд при EXPIRY_SKEW_MS=60000 вызывает частые refresh 200, затем terminal 401; /?reason=expired зациклен, форма не появляется даже после reload. Артефакты: 1139-short-ttl-before.png, 1139-expired-loop.png, журналы /tmp/sj-backend-1139.log и /tmp/next-prod-3108.log. Секреты не извлекались. Нормальное продление с TTL 180 проверяет ведущий агент отдельно.

Статический разбор по superpowers:systematic-debugging: lib/auth.tsx загружает userData даже при session.error; форма app/page.tsx воспринимает user как признак действительного входа и уходит обратно на защищённую страницу. awaitingWorkspace после успешного submit не снимается при terminal отказе. lib/auth-config.ts повторно продлевает уже отвергнутую сессию; refreshToken остаётся в JWT. Это самостоятельные причины непригодного terminal состояния, независимо от причины первоначального 401.

## Решение перед кодом

Terminal error закрывает защищённое поддерево и не предоставляет user синхронно; клиент переводит на форму без полного reload и выполняет cookie cleanup один раз. Повторный login ждёт завершения cleanup, чтобы поздний logout не стёр новую сессию. Форма сбрасывает ожидание рабочего места при terminal error. Запрос прав не запускается для terminal сессии. JWT с terminal error больше не продлевается до нового signIn; refreshToken снимается при отклонении. Окно ротации, grace, TTL/skew, бэкенд и права не расширяются.

UI-UX-Pro-Max: локальный поиск error recovery retry authentication подтвердил Error Recovery (понятное следующее действие) и Accessible Authentication (password manager/paste). Существующая форма и сообщение «Сессия истекла — войдите заново» сохраняются; добавлять другой экран не требуется.

Тесты, новые тесты, сборка и браузер этому агенту прямо запрещены. Проверка реализации здесь только статическая; runtime повтор выполняет ведущий агент после общей сборки.

## Реализация и статическая проверка

2026-09-10. Исполнитель: Кодекс Астра 6. Коммит `331b3809`.

Изменены четыре файла: lib/auth.tsx (terminal context, очистка query cache, мягкий переход на форму, последовательный cleanup/login), app/page.tsx (terminal сообщение и сброс awaitingWorkspace), hooks/use-ops-permissions.ts (terminal выключает запрос и закэшированные права), lib/auth-config.ts (rejected снимает refreshToken, terminal JWT больше не продлевается).

Сохранены safeCallbackUrl, same-origin навигация и callbackUrl с защищённой страницы. На уже открытой форме добавляется reason=expired с сохранением callbackUrl. Неполученная/повреждённая сессия не выдаёт права; backend scope и auth API не менялись. Старый query cache целиком очищается при terminal вместо очистки одних прав, поскольку теперь переход мягкий и повторный вход не должен увидеть данные прежнего пользователя.

Статическое само-ревью: terminal рендер не экспортирует прежнего user даже до исполнения эффектов; защищённое поддерево размонтируется; после очистки cookie форма сохраняется. Повторный вход ожидает cleanup, успешный вход освобождает ref для следующего истечения. При повторном terminal сразу после signIn состояние awaitingWorkspace также снимается зависимостью эффекта. git diff --check: exit 0, без вывода. Коммит: exit 0, 4 files changed, 55 insertions(+), 39 deletions(-). Git сообщил историческое предупреждение gc.log/unreachable loose objects; обслуживание репозитория вне задачи не выполнялось.

Ограничение результата: runtime не подтверждён этим агентом; тесты, сборка, браузер, процессы и данные не трогались. Ведущему агенту передан коммит для общей сборки и проверки восстановления формы/повторного входа. Причина первоначальной гонки при коротком TTL и поведение normal refresh проверяются отдельно; skew и rotation grace этой правкой не расширены. Plane статус этот агент не переводил.
