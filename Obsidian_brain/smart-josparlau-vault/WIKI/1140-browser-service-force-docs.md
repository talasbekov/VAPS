## Семь моделей реестра только на чтение

Каждая ниже открыта через собственный список и первую существующую строку. Заголовок `View`, содержимое read-only, доступны History и Close; Save/Delete отсутствуют. У первой модели дополнительно скриншот `1140-b-force-readonly.png`, у остальных полные DOM деталей в `1140-b-force-readonly.json`. Не создавались записи реестра и не изменялись действующие сотрудники.

| Модель | Назначение ограничения |
|---|---|
| OpsForceRequest | Новая потребность/срок — новая серия заявки, а не правка прежней |
| OpsDepartmentRequest | Новый ответ департамента — новая sequence |
| OpsUnitRequest | История запросов управлениям и связь с directorate_key |
| OpsForceRequestMember | Факт включения сохраняется; исключение removed_at выполняет сервис |
| OpsForceCampaignAssignment | История назначения из пула сохраняется через сервис |
| OpsForceCampaignPoolMember | Факт общего пула сохраняется; исключение выполняет сервис |
| OpsForceCampaignHandover | Передача в расстановку — фиксируемый исторический факт |

Основание: `models_forces.py`, общий `_AppendOnly.admin_readonly=True`, запрет обновления прежней строки в save(); `admin_auto.py` отключает Add/Change/Delete для этой метки. Снять запрет значило бы нарушить действующий инвариант Plane №671. Это осознанное ограничение паритета админки; бизнес-операции «довыделить», «назначить», «исключить», «передать» исполняются на сайте через сервис. Прямого эквивалента этих кнопок в Django сейчас нет.
