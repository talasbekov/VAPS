# Импорт штатки XLSX — Implementation Plan

Исполнитель: Кодекс Астра 6. 2026-09-11. Plane №1175.

**Goal:** команда `import_staffing_xlsx` читает утверждённый XLSX, создаёт дерево по кодам, справочники, сотрудников и штатные единицы; повтор без дублей.
**Architecture:** openpyxl → строгий независимый parser → сверка базы/настроек → отчёт → атомарное применение. Режим по умолчанию read-only; запись только --apply. Внешние идентификаторы выделены в моделях и имеют unique.
**Tech Stack:** существующие Django/PostgreSQL/openpyxl/pytest.
**Spec:** [[Предложения-1174-Импорт-штатки-XLSX]], утверждённый запрос «напиши скрипт под этот файл, но чтобы также создавались подразделения все совпадало».

## Ограничения и решения
Рабочая ветка codex/1175-staffing-xlsx, отдельный worktree /home/erda/.codex/worktrees/roster-1175/Smart Josparlau. Данные заказчика не копировать в Git, не загружать в рабочую БД по поручению только написать скрипт. Родители/типы/уровни — из базы или явной JSON-конфигурации; имена не выдумывать. Неизвестные дата рождения/приёма/пол — NULL при импорте, прежние default сохраняются для совместимости других путей. Невалидный ИИН по умолчанию блокирует запись; явная настройка строки позволяет оставить NULL или задать исправленный. Не удалять отсутствующее в частичном файле. Не занимать чужой слот и не переносить человека молча. Метаданные: Employee.external_id, StaffUnit.external_id/import_order/position_category. Внутренний табельный номер новых записей генерировать XLSX-<personId>, не выдавать personId за реальный табельный номер. Существующие сотрудники по ИИН могут быть привязаны при отсутствии конфликта внешнего id.

## Пробы приёмки
```python
# повтор сохраняет идентификаторы
call_command("import_staffing_xlsx", path, config=config, apply=True)
before = list(StaffUnit.objects.values_list("id", "employee_id"))
call_command("import_staffing_xlsx", path, config=config, apply=True)
assert list(StaffUnit.objects.values_list("id", "employee_id")) == before
# отсутствующий родитель блокирует весь импорт
with pytest.raises(CommandError, match="6984"):
    call_command("import_staffing_xlsx", path, apply=True)
assert not Division.objects.filter(code="6661").exists()
```

Проверки запускаются через pytest-lock и существующий .venv, база worktree изолирована именем. По окончании пользователь получает команду preview/apply и конкретные недостающие поля своего файла.
