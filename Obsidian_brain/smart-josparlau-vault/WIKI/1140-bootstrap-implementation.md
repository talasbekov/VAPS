# Plane №1140 — чистый bootstrap контура

Дата: 10.09.2026. Исполнитель: Кодекс Астра 6.

## Ход работы

- Прочитаны `AGENTS.md`, [[Промпт-тестовый-прод-закрытый-контур]] (блок 3) и [[План-1137-Тестовый-прод-закрытый-контур]]. Применяется только workflow Superpowers; pytest/e2e/smoke и новые тесты запрещены заказчиком.
- Проведён статический аудит сидов. `seed_access_matrix` и `seed_role_accounts` требуют роли из `seed_operations`; полный `seed_operations` добавляет демо-рейтинги, аналитику, отчёты и обращения. Поэтому для чистого bootstrap нужен узкий режим `seed_operations --reference-only`, который останавливается после RBAC, оперативных политик и справочников.
- Повторный аудит границы `seed_operations` выявил, что внутри методов с демо-данными жили и обязательные каталоги: feature flags рейтинга, метрики/периоды/детекторы аналитики, тип отчёта и `OpsFeedbackRegistry`. Они вынесены в reference-only путь; обращения, оценки, события и прочие факты остаются только в `--demo`.

## Решения

- Обычный `bootstrap_contour` создаёт только общие справочники, лестницы должностей/званий, типы статусов, структуру и служебные роли/права. Учётки, штатные единицы и сотрудники в этот режим не входят.
- `--demo` — явный opt-in: после чистой основы добавляет штатку, сотрудников, фото и два набора стендовых учёток. Пароли берутся только из `ACCESS_MATRIX_PASSWORD` и `ROLE_ACCOUNTS_PASSWORD`/соответствующих CLI-аргументов; секретов в коде нет.
- Суперпользователь не создаётся bootstrap-командой; остаётся отдельным шагом рунбука.
- Опциональные demo-секреты проведены из `.env.example` в backend-контейнер через Compose; по умолчанию они пусты и на чистый bootstrap не влияют.
- Перед любой мутацией `--demo` проверяет оба пароля; `seed_access_matrix` больше не печатает секрет в stdout. Демо-фото из wrapper исключены: они не требуются блоком 3, а старый `seed_employee_photos` в Docker вычисляет несуществующего родителя `BASE_DIR` и обрывает опциональный bootstrap до учёток.
- `RUNBOOK.md` включён в состав офлайн-бандла и оба списка SHA-256; `README.md` больше не называет bootstrap будущей работой. Полная пересборка бандла остаётся в разрешённой карточке №1144.
