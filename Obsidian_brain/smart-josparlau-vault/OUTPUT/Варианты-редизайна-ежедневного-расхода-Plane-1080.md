# Два варианта редизайна ежедневного расхода

Исполнитель: Кодекс Астра 6.

> [!warning] Исторический материал
> После уточнения заказчика эта пара вариантов не является целевым решением: экран начальника управления менять не нужно. Актуальные макеты — [[Рабочие-места-ответственного-и-Штаба-Plane-1080]].

Оба варианта убирают три технические вкладки с `/employees`. «Сбор сил на ОМ» становится отдельным пунктом навигации. Пункт «Ежедневный расход» открывает экран по роли: начальнику управления — расход своего управления; ответственному за расход департамента — свод по управлениям; администратору — отдельный обзор организации; оперативному дежурному — свод Службы.

## Вариант A — оперативный список

![[assets/1080/1080-variant-a-operational-list.png]]

Плюсы: знакомая вертикальная структура, видна готовность всех управлений, минимальное обучение, хорошо переносится на узкие экраны. Минус: при большом числе управлений остаётся вертикальная прокрутка.

## Вариант B — рабочая область

![[assets/1080/1080-variant-b-workspace.png]]

Плюсы: система ведёт по шагам, быстрее переключаться между управлениями, выбранное управление остаётся перед глазами. Минус: интерфейс плотнее и менее похож на привычный бумажный расход.

## Рекомендация

Вариант A как базовый: он сохраняет понятную иерархию из найденных образцов, но убирает их широкую «шахматную доску» и ставит действие рядом с состоянием. Из варианта B можно отдельно забрать верхнюю полосу «шаг 1 → шаг 2 → шаг 3», если заказчику понравится подсказка следующего действия.

Рабочий код не менялся. После выбора A/B требуется утвердить дизайн, затем оформить план реализации через Superpowers.
