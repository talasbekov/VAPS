# Установка Smart Жоспарлау

Для нового сервера Linux x86_64 с установленными Docker Compose и Python 3. Интернет не нужен. Это установка без прежних сотрудников и данных.

1. Перенесите архив на сервер. Откройте терминал в папке с архивом и выполните:

```bash
tar -xf smart-josparlau-offline-2026-09-19-1144.tar
cd lan-1144-2026-09-19-final
```

2. Вместо `IP_СЕРВЕРА` укажите адрес вашего сервера, например `192.168.1.10`. Выполните:

```bash
python3 configure.py --ip IP_СЕРВЕРА
bash install.sh
```

Дождитесь завершения установки. Если команда завершилась ошибкой, следующие шаги не выполняйте — сохраните текст ошибки.

3. Создайте администратора:

```bash
bash ctl.sh exec backend python manage.py createsuperuser
```

Введите логин и пароль по подсказкам. При вводе пароль не отображается — это нормально.

4. Откройте в браузере, подставив тот же адрес сервера:

- Админка: `http://IP_СЕРВЕРА:8300/admin/` — войдите созданным администратором.
- Портал: `http://IP_СЕРВЕРА:3300/`.

Пользователей, их права и рабочие данные настройте в админке.

Если система на сервере уже установлена и содержит данные, эти шаги не применяйте: для неё нужен перенос резервной копии.
