# Отчёты по Службе

Исполнитель: Кодекс Астра 6.

## Назначение

Каталог официальных документов по личному составу и ежедневному расходу Службы. Он является визуальным ориентиром для [[../Охранные-мероприятия/Отчёты-по-ОМ|Отчётов по ОМ]], но не содержит документы ОМ и не разделяет с ними генератор по умолчанию.

## Текущий экран

Маршрут `/reports` сейчас построен карточками и содержит живой «Расход Л/С» с выбором даты, таблицей строевой записки и выгрузкой по подразделению; остальные карточки — заглушки. Точное подтверждение, что именно этот экран, а не ранее переданный макет, является визуальным эталоном, остаётся вопросом `[ОТЧ-ВОП-01]`.

## Целевой контракт

- Дневные данные и версии берутся из единого процесса [[Ежедневный-расход-Службы|ежедневного расхода]], не рассчитываются вторично.
- Доступ ограничивается областью роли; оперативный дежурный читает всю организацию по отдельному глобальному гранту.
- Пользовательский формат ежедневного расхода пока не утверждён: PDF-only относится к ОМ, а для Службы открыт `[РАСХ-ВОП-03]`.
- Заглушка не считается реализованным отчётом и должна быть явно помечена как незавершённая.
