# Законы об ОМ

> В сайдбаре прототипа отсутствует; модуль существует в коде.

## Назначение
Нормативная база охранных мероприятий: поиск и просмотр законов и нормативных документов, регулирующих ОМ.

## Маршрут и доступ
`/security-ops/laws`; права проверяет страница (use-ops-permissions).

## Экраны и флоу
Из кода: страница «Законы об ОМ» (группа «Оперативная работа») — «Поиск по нормативной базе»: поиск по названию, номеру документа или содержанию.

## Данные и API
Живой бэк с 21.08.2026: `GET /api/ops/legal-documents/` (модель `OpsLegalDocument`, kind/status под CheckConstraint, правка через Django Admin, сид `seed_legal_documents` — 8 документов). Право: `event.view`. Файлы документов система не хранит — `fileUrl` честно null. Мок MSW остаётся для демо через `NEXT_PUBLIC_OPS_MOCK_DOMAINS=legal-documents`.

## Ограничения и расхождения
Не зафиксированы.
