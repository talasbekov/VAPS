# Оперативный рейтинг

> В сайдбаре прототипа отсутствует; модуль существует в коде.

## Назначение
Оценивание участников охранных мероприятий и агрегированный рейтинг сотрудников: взаимные оценки «старший ↔ сотрудник», агрегаты, аналитика и выгрузки.

## Маршрут и доступ
`/security-ops/ratings` (+ подстраницы `workspace`, `evaluations`, `employees/[employeeId]`, `analytics`, `export`, `audit`); права проверяет страница (use-ops-permissions).

## Экраны и флоу
Из кода (группа «Оценка и отчётность»):
- «Оперативный рейтинг» — сводная таблица: сотрудник, агрегат, учтено оценок, период, состояние; методика расчёта.
- «Оценивание участников» (workspace): «Мне нужно оценить» / «Отправленные мной», сводка мероприятия, разделы оценивания.
- «Итоговые оценки участников»: направления «Старший → сотрудник» и «Сотрудник → старший», оценка человека и системная оценка по умолчанию.
- «Агрегированный рейтинг участника»: агрегат и агрегированная динамика по сотруднику.
- «Аналитика рейтинга»: защита от малых выборок («Недостаточно данных для безопасного отображения»); при выключенном флаге — «рейтинг выключен сервером».
- «Выгрузка рейтинга»: асинхронные работы (В очереди / Формируется / Ошибка / Отменён), агрегированная сводка и индивидуальные оценки.
- «Журнал оценивания» (audit): отправки, изменения значений, попытки снижения без комментария, исправления.

## Данные и API
Живой бэк: `operations` — OpsEvaluationEvent, OpsEvaluationWorkItem, OpsEventEvaluation, OpsEvaluationCorrection, OpsRatedParticipant, OpsRatingGroup, OpsRatingDynamicsPoint, OpsRatingExportJob/Artifact, OpsRatingAuditEntry, OpsRatingFeatureFlags.

## Ограничения и расхождения
Не зафиксированы.
