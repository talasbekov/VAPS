### Мутация №9 — что именно произошло на ТЕКУЩЕМ sha `dee419f`

Сборка **не упала**: `npm run build` → exit 0. В бандл уехал **голый идентификатор**:

```js
const Mx="0.1.0",Dx=dee419f;
//        ^строка       ^идентификатор → ReferenceError в браузере
```

Vitest при этом умер на уровне пула: `Failed to load custom "defines": dee419f is not defined`.

Это средняя строка таблицы AC-1 («молча-фатальный»): симптом зависит от того, как
сегодня выглядит короткий sha — `dee419f` начинается с буквы и потому является
валидным JS-идентификатором. На sha из одних цифр уехало бы **число**, на `0.1.0`
сборка **упала бы**. «У меня собралось» не доказывает ничего.

### Две вакуумности, пойманные в СВОИХ ЖЕ тестах

1. **`void stderr`.** Первая редакция `build-constants.test.mjs` «проверяла»
   молчание шва вне git через `execFileSync`, который на успешном прогоне
   отдаёт только stdout — ассерта не было вовсе. Переписано на `spawnSync` с
   явной проверкой `stderr === ''`.
2. **Пустой `<p>` вместо метки.** Ассерт «нет текста `сборка`» вакуумен:
   `buildLabel('')` и так отдаёт пустую строку, поэтому снятый гард отрисовал бы
   ПУСТОЙ абзац и тест остался бы зелёным. Класс «дубль-гард → вакуумная проба»
   (урок 10.6, MEDIUM). Добавлен счёт узлов (`querySelectorAll('p')`) — проба
   P10 после этого краснеет.
