## 2. Что прошло хорошо

1. **Конвейер story-automator доказал себя на фронтенде.** 6 стори одной сессией, ноль ретраев шагов, ноль откатов, ноль эскалаций по коду. Единственный сбой за прогон — инфраструктурный (tmux), не кодовый.
2. **Невакуумность как канон эпика.** Урок 8.1 («0 JS-файлов = вакуумный pass size-gate») стал явным AC в 8.2/8.3 и дисциплиной всех восьми стори: каждая доказывала красноту гейта живой пробой до зелёного прогона. Счётчик lint-canon рос монотонно 13+6 → 24+9.
3. **Двухслойный enforcement как переносимая идиома:** eslint+deps-gate (8.2) → pytest-drift + schema-check (8.3, явное «зеркало 8.2»). Слои стек-локальны: фронт-гейт не зовёт python, бэк-гейт не зовёт npm; закоммиченный `schema.yaml` — handoff-артефакт.
4. **Контурные ловушки сняты до кода.** Главная развилка эпика — Tailwind v4 требует FF128+ при цели FF100 — поймана на create-story 8.7, а не в рантайме: жёсткий пин tailwindcss@^3.4 + спутники по эпохе + бан-лист v4-пакетов. Аналогично: ds-bundle `.jsx` оказались заглушками → рукописный вендоринг по канону new-york v3 со сверкой байт-в-байт (8.8: woff2 сверены `cmp` с tarball).
5. **QA-проход институционализировался с 8.5 и каждый раз находил реальные пробелы:** тост с нулевым покрытием и нетестированная Providers-композиция (8.5), цена ретраев 401 и remount-«F5» (8.6), 13 E2E layout (8.7), 5 e2e печати (8.8).
6. **Ревью ловит настоящие баги, а не только стиль.** 8.6: стейл-права `['me']` при смене пользователя без logout; deny≠fail в RequirePermission (сбой бэка рендерил «Доступ запрещён»). Оба закрыты красными пробами вживую.
7. **Бюджеты держатся с запасом:** 150/300 KB gzip после подключения react-query, react-router, RHF+zod, Radix; каждый прирост зафиксирован в Dev Record.

## 4. Ключевые уроки (переносимые)

1. **Недоказанный бан = вакуум.** Каждый канал enforcement — отдельной красной фикстурой; негативный контроль обязателен (иначе конфиг «всё запрещено» тоже пройдёт); ассертить ruleId + severity===2.
2. **FF100 диктует стек, а не наоборот:** Tailwind v3 (не v4), без `:has()`/`h-dvh`/`@page size`/`color-mix()`; `AbortSignal.timeout` — граница; двойная защита: esbuild-таргет держит синтаксис, eslint-plugin-compat — API. Пиксельная верность — только ручной релизный смоук на архивном FF100 (Playwright не умеет).
3. **Версии пакетов — контракт.** Пины + registry-снимок на дату create-story; апгрейд генератора/шаблона = осознанный regen-коммит, не побочный эффект.
4. **Тест-механика jsdom — канон с 8.5:** `// @vitest-environment jsdom` первой строкой, jest-dom per-file (не в общий setup), явный `afterEach(cleanup)`, реальная Providers-композиция вместо локальных обёрток, MSW-капчеры массивом, wildcard `*/api/…` в node.
5. **Смок печати — только против прод-сборки:** dev-сервер инжектит CSS по-модульно и маскирует утечку каскада; конкатенация Vite проявляется лишь в build+preview.
6. **Матрица boundaries работает и на тестах** (инцидент 8.6: тест в shared импортировал features) — тесты, которым нужен кросс-слойный флоу, живут в `app/`.
7. **Стори из решения/дефера + вариации размера (>5 файлов) — легализуются явной пометкой в самой стори** (прецеденты 8.6/8.7/8.8) — механизм E4-AI#2 работает в форме Д/Q, без правки epics.md.
