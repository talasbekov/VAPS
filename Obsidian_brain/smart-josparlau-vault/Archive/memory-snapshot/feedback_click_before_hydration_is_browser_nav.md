Проба «переход по меню не перезагружает документ» (маркер в `window`, который
обязан пережить навигацию) даёт ложный красный, если кликнуть по `<Link>` до
того, как React отгидратировал страницу: до этого момента это обычный `<a>`, и
браузер уходит в полную навигацию. `waitForSelector` по разметке не помогает —
серверный HTML уже отрисован.

**Как применять:** ждать признак ЖИВОГО клиента, а не наличия узла. В
PersonalRecordFront такой признак — `ThemeToggle`: до `mounted` он отдаёт
disabled-заглушку с общим `aria-label="Переключение темы"`, после —
`aria-label^="Переключить на"`. Ждать этот селектор перед кликом.

Общий приём: искать элемент, чей ТЕКСТ или атрибут меняется только на клиенте
(mounted-флаг, локальное время, значение из localStorage).
