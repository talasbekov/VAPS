2. Прочитать `docs/frontend/FRONTEND_TRACEABILITY_MATRIX.md` для списка
   Not started экранов — выбор следующего направления обычно за пользователем
   (паттерн этой сессии: предлагаю варианты, пользователь выбирает одно
   слово типа "Duties", я делаю полный вертикальный срез с тестами).
3. Читать прототип (`Smart Josparlau (Прототип HTML)/Smart Josparlau.dc.html`
   и `Прототип/*.dc.html`) ПЕРЕД реализацией каждого нового экрана — прямое
   указание пользователя раньше в этой работе, не полагаться только на
   пересказ.
4. После каждого вертикального среза: `npm run gate` (из `frontend/`),
   `npm run test:e2e` + `npm run test:e2e:mock`, ручная проверка в браузере
   (Preview-инструмент, логин `demo-admin` — wildcard-persona), обновить все
   8 memory-файлов, закоммитить (пользователь разрешил коммитить сам, без
   переспрашивания на каждый инкремент).

**How to apply:** это единственный источник, где живёт актуальный git SHA и
список коммитов — код и `docs/frontend/*.md` дают "что", это memory даёт
"куда смотреть первым и как продолжать в том же темпе/стиле".
