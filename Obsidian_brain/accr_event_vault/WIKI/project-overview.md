# Обзор проекта — eventproject

> Обновлено: 2026-06-11 (полное пересканирование, уровень exhaustive).

## Назначение

**eventproject** — система управления аккредитацией участников охранных мероприятий Республики Казахстан. Автоматизирует регистрацию делегаций: сбор персональных данных (включая шифруемый ИИН), фото и сканов документов, формирование заявок, их проверку и экспорт для пропускных систем, а также автоматический импорт участников из внешних систем регистрации (KazEnergy, Avalon/KazExpo).

## Ключевые возможности

- Заявки на аккредитацию с жизненным циклом `Active → Checking → Sent → Exported` и delta-экспортом (ExportLog).
- Трёхъязычный интерфейс: русский, казахский (`/kz/`), английский (`/en/`).
- RBAC: superuser / superoperator / operator / user; видимость событий по назначению.
- DRF REST API `/api/v1/` (события, категории, rbac-check) с ошибками RFC 7807.
- Шифрование ИИН at rest (Fernet), аудит-лог всех операций с участниками, JSON-логирование.
- Защита: django-axes (брутфорс), django-ratelimit (20/h на загрузки), HSTS/CSRF Strict, ролевые таймауты сессий.
- Импорт анкет из KazEnergy/Avalon каждые 2 минуты (pull + ACK).
- QR-приложение: генерация QR-кода по ИИН с полной валидацией ИИН РК.
- Экспорт: JSON участников, ZIP-архивы фото/документов.

## Роли пользователей

| Роль | Возможности |
|------|-------------|
| superuser | Всё: мероприятия, операторы, экспорт, админка `/embankment/` |
| superoperator | DRF API событий/категорий, все события |
| operator | Свои события: заявки и участники |
| user | Fallback без прав |

## Технологический стек (кратко)

Python 3.10 · Django 5.1.3 · DRF 3.15.2 · PostgreSQL 15 · Celery 5.5.3 + Redis 7.4 · Gunicorn · Docker Compose. Полная таблица — в [architecture.md](./architecture.md).

## Структура репозитория

Монолит: ядро `eventproject/` (модели, view-слой по доменам, DRF, middleware, тесты), справочники `directories/`, языковые зеркала `en_event/`/`kz_event/`, QR-модуль `qr_event/`, шаблоны `templates/`. Подробнее — [source-tree-analysis.md](./source-tree-analysis.md).
