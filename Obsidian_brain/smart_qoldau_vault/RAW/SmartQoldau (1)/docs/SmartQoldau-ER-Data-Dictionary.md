# SmartQoldau — словарь данных для ER-схемы

Основано на текущей версии прототипа (после контрольной сверки). Поля даны как найдены в интерфейсе — тип значения и, где применимо, перечень enum-вариантов.

## 1. Пользователь / Клиент

**User**
- id — текст (внутренний)
- anon_id — текст, формат `#XXXX` (4 цифры, напр. `#1048`)
- name — текст, опционально (не обязателен при анонимном режиме)
- email — текст, опционально
- phone — текст, формат `+7 XXX XXX XX XX`
- city — enum: Астана / Алматы / Шымкент
- is_anonymous — boolean
- is_premium — boolean
- is_corporate — boolean (B2B/B2G доступ)
- corporate_contract_code — текст, формат `SQ-XXXX-YYYY` (B2B, вводит сам клиент)
- created_at — дата

**Premium subscription**
- plan — enum: monthly (2990₸) / yearly (23900₸/год = 1990₸/мес)
- active — boolean
- activated_at — дата
- perks — фиксированный список: приоритетный подбор, безлимит контента (медитации/статьи/дыхательные практики). Без скидки на сессию.

## 2. Специалист

**Specialist (карточка каталога)**
- id, initial, name — текст
- role/specialization — текст
- rating — число 0.0–5.0
- experience — текст (напр. «6 лет»)
- city — enum (см. выше)
- languages — список текстов
- price — число ₸, диапазон 15 000–35 000 (0 для практикантов)
- formats — enum-массив: chat / audio / video
- bio — текст
- is_new (Старт-пакет, скидка клиенту 15%) — boolean
- is_intern — boolean
- university — текст (только если is_intern)
- status_online — enum: online / offline

**Specialist (полный профиль, доп. поля)**
- reviews[] — { stars: число 1–5, date, text, anon_client_id }
- specialization_tags — список текстов
- session_count — число
- avg_response_time — текст

**Verification — обычный специалист**
- full_name, iin (12 цифр), phone
- specialization — текст
- documents[4] — enum статус каждого: удостоверение личности / диплом об образовании / сертификаты / документы о квалификации — статус: пусто / загружен / подтверждено
- submitted_at — дата
- sla_hours — число (24ч лимит)
- status — enum: ожидает / просрочено / одобрено / отклонено
- rejection_reason — текст (если отклонено)
- duplicate_iin_flag — boolean
- duplicate_iin_history — текст

**Verification — студент-практикант**
- full_name, university, course_specialty — текст
- b2g_contract_code — текст, формат `SG-XXXX-YYYY` (вводит студент, НЕ клиент)
- documents[2] — справка с места учёбы / подтверждение специальности-курса
- supervisor_name — текст (назначается админом)
- submitted_at, status
- после одобрения → is_intern = true

**Tariff (тарифный пакет специалиста)**
- tier — enum: start / basic / pro / top
- price_per_month — число ₸: 0 / 0 / 12000 / 20000
- commission — число %: 0 / 15 / 13 / 10–11
- trial_days_left — число (только для tier=start)
- visibility — enum: пониженная / стандартная / приоритет-2 / приоритет-1

## 3. Сессия / Консультация

**Session**
- id, client_anon_id, specialist_id
- topic — enum (см. раздел 8)
- format — enum: chat / audio / video
- scheduled_at — дата/время
- duration — число (мин)
- price_fixed — число ₸ — **снимок цены на момент записи**, не пересчитывается при изменении цены в профиле специалиста
- status — enum:
  - upcoming (запланирована)
  - active
  - completed (завершена)
  - cancelled_free (отмена >2ч, возврат 100%)
  - cancelled_partial (отмена <2ч, возврат 50%, компенсация специалисту 50%)
  - noshow_client (клиент не пришёл — специалист получает компенсацию)
  - noshow_specialist (специалист не вышел на связь — клиенту полный возврат)
  - tech_issue
- rating — число 1–5 (после completed)
- can_complain_until — дата (48ч после completed)

## 4. Платежи и выплаты

**Payment method** — enum: card (номер/срок/CVC/имя/бренд Visa|Mastercard) / kaspi_pay / apple_pay / google_pay / corporate (B2B/B2G — «Оплачено компанией»)

**Income (у специалиста)**
- today_total, week_total, month_total — число ₸
- transactions[] — { topic, format, date, amount (зафиксированная сумма), status: начислено/выплачено }

**Payouts**
- available_balance — число ₸
- history[] — { amount, date, status: обрабатывается/выплачено/отклонено }

**Commission** — отображается в веб-кабинете как строка транзакции: сумма → «−комиссия ₸» → итог; ставка = ставка тарифа специалиста (0/15/13/10–11%)

## 5. Жалобы

**Complaint**
- id, session_id, client_anon_id, specialist_id
- type — enum: клиент→специалист / специалист→клиент / спор по no-show
- reason — enum: неэтичное поведение / не вышел на связь / техпроблема / другое
- description — текст (обязательно)
- has_attachment — boolean (только формат=chat)
- submitted_at — дата
- status — enum: новая / в работе / закрыта
- specialist_response — текст (до решения админа)
- specialist_response_status — enum: ожидает ответа / на рассмотрении / решено
- resolution — enum: полный возврат / частичный возврат / отказ / страйк специалисту
- admin_comment — текст
- prior_complaints_count — число

## 6. B2B / B2G

**B2B Contract**
- id, company_name, contact_name, contact_position
- start_date, end_date
- session_pool_total, session_pool_used — число
- discount_percent — число/текст
- status — enum: активен / истекает (<14 дней) / завершён
- corporate_code — `SQ-XXXX-YYYY`
- employees[] — { email, activated_at } — без деталей тем/специалистов

**B2G Contract**
- id, org_name (вуз/ведомство), contact_name, contact_position
- contract_number — текст, опционально
- start_date, end_date
- students_count — число
- work_model — enum: платно со скидкой / бесплатно (практика)
- status — enum (как выше)
- b2g_code — `SG-XXXX-YYYY`
- students[] — { full_name, verification_status, supervisor_name }
- sessions_conducted — число

**Форма «Для бизнеса» (сайт)** — company, contact, email, phone, employees_count, comment
**Форма «Для вузов» (сайт)** — org, contact, position, email, phone, students_count, comment

## 7. Уведомления

| Получатель | Событие | Текст |
|---|---|---|
| Клиент | No-show специалиста | «Специалист не вышел на связь» / «Средства возвращены в полном объёме» |
| Клиент | Напоминание (за 1 час) | «Видеоконсультация с [специалист] начнётся через 1 час» |
| Клиент | Результат жалобы | «Решение по вашей жалобе принято» → «Мои жалобы» |
| Клиент | Подтверждение сессии | «[Специалист] ждёт вас сегодня в [время]» |
| Клиент | Сообщение в чате, оценка, статья | — |
| Специалист | Жалоба на вас | «Клиент #XXXX подал жалобу... требуется ваш ответ» |
| Специалист | Отмена клиентом <2ч | «Компенсация 50% зачислена на баланс» |
| Специалист | No-show клиента | «Средства зачислены на баланс в полном объёме» |
| Специалист | Результат жалобы | → «Мои жалобы и споры» |
| Специалист | Истечение Старт-периода | «Через 3 дня — переход на Базовый тариф (15%, стандартная видимость)» |
| Специалист | Напоминание (за 1 час), новая заявка, выплата, изменение расписания | — |

Канал везде — push (email/SMS не отображены в интерфейсе).

## 8. Темы обращения

Полный список (12): Тревога и стресс, Отношения, Семья, Эмоциональное выгорание, Самооценка, Панические состояния, Зависимости, Жизненные кризисы, Одиночество, Проблемы со сном, Работа и карьера, Другое.

**Тяжёлые темы** (`HEAVY_TOPICS`, жёстко заданы): Депрессия/апатия, Зависимости — практиканты скрыты. Остальные — лёгкие.

## 9. Админ-панель

- **Дашборд**: активные сессии, заявки на верификацию, открытые жалобы, доход сегодня/неделю/месяц, график 7 дней
- **Верификация**: 2 потока (специалисты / практиканты), поля — см. раздел 2
- **Жалобы**: поля — см. раздел 5
- **Рассылки**: type (маркетинг/инцидент-алерт), segment, channels (push/email), title, body, history[]
- **Финансы*** (только супер-админ): доход платформы, выплачено, к выводу, доход B2B, разбивка по пакетам, лог транзакций
- **Специалисты**: таблица + карточка (смена пакета — заблокирована для модератора), блокировка
- **Клиенты**: таблица + карточка, блокировка
- **B2B/B2G-контракты*** (только супер-админ): см. раздел 6
- **Настройки*** (только супер-админ): пакеты (цена/комиссия), темы, контент, журнал действий

**Роли**: Супер-админ — полный доступ. Модератор — только Верификация + Жалобы; Финансы/B2B/B2G/Настройки заблокированы; смена тарифа специалиста заблокирована отдельно.
