# E1 «Ядро бэкенда» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Рабочий каркас бэкенда SmartQoldau: NestJS + PostgreSQL/Redis, аутентификация (SMS-код, JWT+refresh, гостевой режим, конверсия гостя), справочник из 12 тем (ru/kz), audit log, единый формат ошибок, OpenAPI.

**Architecture:** Модульный монолит NestJS (TypeScript), Prisma ORM поверх PostgreSQL, Redis для будущих таймеров/presence (в E1 только подключение). Контракт-first: Swagger-декораторы с первого эндпоинта. Все последующие эпики (E2–E5) строятся на модулях этого плана.

**Tech Stack:** Node 22 LTS, NestJS 10, Prisma 5, PostgreSQL 16, Redis 7, Jest + supertest, @nestjs/jwt, @nestjs/config + Joi, @nestjs/swagger. Docker Compose для dev-окружения.

## Global Constraints

- Монорепо: код бэкенда — в `backend/` от корня `smart_qoldau/` (структура — мастер-план [[План разработки MVP SmartQoldau]]).
- Денежные суммы — integer в тиынах (в E1 денежных полей нет, но правило действует на все будущие миграции).
- Телефоны — только формат KZ: регэксп `^\+77\d{9}$`.
- Повторная отправка SMS-кода — не чаще 1 раза в 45 секунд (прототип: «повтор через 00:45»).
- Access-токен 15 минут, refresh 30 дней с ротацией; refresh хранится только хэшем.
- Справочник тем — ровно 12 тем Р-14, поля ru и kz обязательны.
- Каждый статусный переход сущностей пишется в `audit_log` (ТЗ §4.5).
- Единый формат ошибок: `{ "error": { "code": string, "message": string, "details"?: object } }`.
- API под префиксом `/v1`; каждый эндпоинт задокументирован Swagger-декораторами в том же коммите.
- Эксперт никогда не получает ПД клиента — в E1 закладывается разделение DTO (UserPublicDto без phone).
- Локаль ответа справочников: `?locale=ru|kz`, по умолчанию `ru`.

`backend/src/common/filters/app-exception.filter.ts`:

```typescript
import { ArgumentsHost, Catch, ExceptionFilter, HttpException, HttpStatus } from '@nestjs/common';

const CODE_BY_STATUS: Record<number, string> = {
  400: 'VALIDATION_FAILED', 401: 'UNAUTHORIZED', 403: 'FORBIDDEN',
  404: 'NOT_FOUND', 409: 'CONFLICT', 429: 'RATE_LIMITED', 500: 'INTERNAL',
};

export function apiError(code: string, message: string, status: number): never {
  throw new HttpException({ code, message }, status);
}

@Catch()
export class AppExceptionFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse();
    const status = exception instanceof HttpException ? exception.getStatus() : HttpStatus.INTERNAL_SERVER_ERROR;
    const body = exception instanceof HttpException ? exception.getResponse() : null;
    const code = (typeof body === 'object' && body && 'code' in body)
      ? (body as any).code : CODE_BY_STATUS[status] ?? 'INTERNAL';
    const message = (typeof body === 'object' && body && 'message' in body)
      ? String((body as any).message) : 'Internal server error';
    const details = (typeof body === 'object' && body && 'details' in body) ? (body as any).details : undefined;
    res.status(status).json({ error: { code, message, ...(details ? { details } : {}) } });
  }
}
```

В `main.ts`: `app.useGlobalFilters(new AppExceptionFilter())` и `app.useGlobalPipes(new ValidationPipe({ whitelist: true, exceptionFactory: (e) => new HttpException({ code: 'VALIDATION_FAILED', message: 'Validation failed', details: e }, 400) }))`.

async requestCode(phone: string): Promise<void> {
  const existing = await this.prisma.smsCode.findUnique({ where: { phone } });
  if (existing && Date.now() - existing.lastSentAt.getTime() < 45_000)
    apiError('SMS_RATE_LIMITED', 'Повторная отправка возможна через 45 секунд', 429);
  const code = String(randomInt(0, 10_000)).padStart(4, '0');
  const codeHash = await bcrypt.hash(code, 10);
  const data = { codeHash, attempts: 0, lastSentAt: new Date(), expiresAt: new Date(Date.now() + 5 * 60_000) };
  await this.prisma.smsCode.upsert({ where: { phone }, update: data, create: { phone, ...data } });
  await this.sms.send(phone, `SmartQoldau: код входа ${code}`);
}

- [ ] **Step 2: Реализация**

`AuthService.verifyCode(phone, code)`: найти SmsCode → если нет или `expiresAt < now` → `SMS_CODE_EXPIRED` 400; `attempts >= 5` → `SMS_CODE_INVALID` 400; `bcrypt.compare` неверен → инкремент attempts, `SMS_CODE_INVALID` 400; верен → удалить SmsCode, `prisma.user.upsert({ where: { phone }, update: {}, create: { phone } })`, вернуть `issueTokens(user)` + user.

`issueTokens(user)`:

```typescript
async issueTokens(user: User) {
  const accessToken = await this.jwt.signAsync({ sub: user.id, isGuest: user.isGuest });
  const refreshToken = randomBytes(48).toString('base64url');
  await this.prisma.refreshToken.create({
    data: {
      userId: user.id,
      tokenHash: createHash('sha256').update(refreshToken).digest('hex'),
      expiresAt: new Date(Date.now() + this.refreshTtlDays * 86_400_000),
    },
  });
  return { accessToken, refreshToken };
}
```

`refresh(refreshToken)`: найти по sha256-хэшу → нет / `revokedAt` / истёк → `UNAUTHORIZED` 401; иначе проставить `revokedAt = now` и выдать новую пару. `JwtStrategy` (passport-jwt, secret из конфига), `JwtAuthGuard`, декоратор `@CurrentUser()` (`npm i @nestjs/jwt @nestjs/passport passport passport-jwt && npm i -D @types/passport-jwt`).
