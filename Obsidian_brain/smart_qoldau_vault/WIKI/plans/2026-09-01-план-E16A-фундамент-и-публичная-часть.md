**Goal:** Публичная часть SmartQoldau — каталог, профиль специалиста, темы —
работает как настоящий веб: серверный рендер, индексация, живой DOM; плюс
фундамент (каркас, клиент API, BFF-авторизация, тесты), на котором дальше
строятся оба кабинета.

**Architecture:** Один Next-проект: `landing/` переименовывается в `web/`,
маршруты разводятся на группы `(public)` / `(client)` / `(expert)`. Публичные
страницы — серверные компоненты с ревалидацией. Сессия — BFF: токены в
httpOnly-cookie, браузер их не видит, Route Handlers проксируют к NestJS.
NestJS остаётся единственным владельцем данных: Next не знает Prisma.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, Tailwind,
next-intl (ru/kz), Jest + Testing Library (юниты), Playwright (сквозные),
Radix (примитивы), zod, openapi-typescript.

**Spec:** `WIKI/plans/2026-09-01-дизайн-E16-веб-приложение.md`

**Plane:** E16-1 … E16-6, E16-15, E16-16, E16-17 (Plane 38–43, 52–54).

## Global Constraints

- **Прототип обязателен.** Раскладки берутся из `docs/Прототип/`
  (`SmartQoldau Web - Каталог`, `Поиск специалиста`, `Профиль психолога`,
  `Выбор темы`, `Материалы`). Придумывать раскладку, когда экран нарисован,
  нельзя.
- **Вёрстка — только через навык `ui-ux-pro-max`**, до первой строки
  разметки (`CLAUDE.md`).
- **TDD:** тест → красный → минимальная реализация → зелёный → коммит.
- **Тесты на Jest, не Vitest.** В `landing/` уже настроен `next/jest` с
  ручной транспиляцией ESM (`next-intl`, `use-intl`, `intl-messageformat`,
  `@formatjs/*`) — конфигурация выстрадана, не переписывать.
- **Локали:** `ru` (по умолчанию) и `kz`, ровно как в
  `lib/i18n/routing.ts`. Новых локалей не заводить.
- **PII-инвариант:** публичная карточка эксперта собирается бэкендом
  явным перечислением полей (`ExpertPublicDto`). Фронт не добирает
  недостающее из других эндпоинтов.
- **Базовый адрес API:** `process.env.NEXT_PUBLIC_API_BASE_URL`, дефолт
  `http://localhost:3000/v1` (как в `landing/lib/api.ts`).
- **Next не ходит в базу.** Никаких Prisma, SQL и бизнес-правил в `web/`.

```ts
// web/lib/api/public.ts
import type { components } from './generated';

export const API_BASE_URL = process.env.NEXT_PUBLIC_API_BASE_URL ?? 'http://localhost:3000/v1';

export type ExpertPublic = components['schemas']['ExpertPublicDto'];
export type Topic = components['schemas']['TopicDto'];

export type ListExpertsParams = {
  topic?: string;
  language?: string;
  format?: string;
  sort?: 'price_asc' | 'price_desc' | 'rating';
  take?: number;
  skip?: number;
};

function toQuery(params: Record<string, string | number | undefined>): string {
  const search = new URLSearchParams();
  for (const [key, value] of Object.entries(params)) {
    if (value !== undefined && value !== '') search.set(key, String(value));
  }
  const query = search.toString();
  return query ? `?${query}` : '';
}

// Публичные списки кэшируются на пять минут: каталог меняется медленно,
// а каждый заход из поиска иначе бьёт в бэкенд.
export async function listExperts(params: ListExpertsParams): Promise<ExpertPublic[]> {
  try {
    const response = await fetch(`${API_BASE_URL}/experts${toQuery(params)}`, {
      next: { revalidate: 300, tags: ['experts'] },
    });
    if (!response.ok) return [];
    return (await response.json()) as ExpertPublic[];
  } catch {
    return [];
  }
}

export async function getExpert(id: string): Promise<ExpertPublic | null> {
  try {
    const response = await fetch(`${API_BASE_URL}/experts/${id}`, {
      next: { revalidate: 300, tags: ['experts', `expert:${id}`] },
    });
    if (!response.ok) return null;
    return (await response.json()) as ExpertPublic;
  } catch {
    return null;
  }
}

export async function listTopics(): Promise<Topic[]> {
  try {
    const response = await fetch(`${API_BASE_URL}/topics`, {
      next: { revalidate: 3600, tags: ['topics'] },
    });
    if (!response.ok) return [];
    return (await response.json()) as Topic[];
  } catch {
    return [];
  }
}
```

// web/e2e/a11y.spec.ts
import { test, expect, type Page } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

export async function expectNoA11yViolations(page: Page) {
  const { violations } = await new AxeBuilder({ page })
    .withTags(['wcag2a', 'wcag2aa'])
    .analyze();

  expect(violations.map((v) => `${v.id}: ${v.help}`)).toEqual([]);
}

test('главная не нарушает WCAG 2 AA', async ({ page }) => {
  await page.goto('/ru');
  await expectNoA11yViolations(page);
});

test('до основного содержимого можно дойти одним Tab', async ({ page }) => {
  await page.goto('/ru');
  await page.keyboard.press('Tab');

  await expect(page.getByRole('link', { name: /основному содержимому/i })).toBeFocused();
});

  topic?: string;
  language?: string;
  format?: string;
  sort?: string;
};

function hrefWith(basePath: string, selected: Selected, key: keyof Selected, value: string): string {
  const next: Selected = { ...selected };
  // Повторное нажатие снимает фильтр: иначе с клавиатуры выбор не отменить.
  if (next[key] === value) delete next[key];
  else next[key] = value;

  const search = new URLSearchParams(
    Object.entries(next).filter(([, v]) => Boolean(v)) as [string, string][],
  ).toString();
  return search ? `${basePath}?${search}` : basePath;
}

export default function CatalogFilters({
  topics,
  selected,
  basePath,
}: {
  topics: Topic[];
  selected: Selected;
  basePath: string;
}) {
  return (
    <nav aria-label="Фильтры каталога" className="flex flex-wrap gap-2">
      {topics.map((topic) => {
        const active = selected.topic === topic.slug;
        return (
          <Link
            key={topic.slug}
            href={hrefWith(basePath, selected, 'topic', topic.slug)}
            aria-current={active ? 'true' : undefined}
            className={
              active
                ? 'rounded-full bg-primary px-4 py-2 text-sm font-bold text-white'
                : 'rounded-full bg-chip px-4 py-2 text-sm font-bold text-ink'
            }
          >
            {topic.name}
          </Link>
        );
      })}
    </nav>
  );
}
```

// web/lib/auth/csrf.ts
const SITE_URL = process.env.NEXT_PUBLIC_SITE_URL ?? 'http://localhost:3000';

// Сессия живёт в cookie, значит браузер приложит её и к запросу,
// который инициировал чужой сайт. Совпадение Origin — дешёвая и
// надёжная проверка; SameSite=Lax её дублирует, но не заменяет.
export function assertSameOrigin(request: Request): void {
  const origin = request.headers.get('origin');
  if (!origin || origin !== SITE_URL) {
    throw new Error('CSRF: запрос пришёл с чужого происхождения');
  }
}

// web/lib/auth/cookies.ts
import { cookies } from 'next/headers';
import type { NextResponse } from 'next/server';

export const ACCESS_COOKIE = 'sq_at';
export const REFRESH_COOKIE = 'sq_rt';

const BASE = {
  httpOnly: true,
  secure: process.env.NODE_ENV === 'production',
  sameSite: 'lax' as const,
  path: '/',
};

export function setSessionCookies(
  response: NextResponse,
  tokens: { accessToken: string; refreshToken: string },
): void {
  response.cookies.set(ACCESS_COOKIE, tokens.accessToken, { ...BASE, maxAge: 15 * 60 });
  response.cookies.set(REFRESH_COOKIE, tokens.refreshToken, { ...BASE, maxAge: 30 * 86_400 });
}

export function clearSessionCookies(response: NextResponse): void {
  response.cookies.set(ACCESS_COOKIE, '', { ...BASE, maxAge: 0 });
  response.cookies.set(REFRESH_COOKIE, '', { ...BASE, maxAge: 0 });
}

export async function readAccessToken(): Promise<string | null> {
  return (await cookies()).get(ACCESS_COOKIE)?.value ?? null;
}

  const upstream = await fetch(`${API_BASE_URL}/auth/verify-code`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: await request.text(),
  });

  const payload = await upstream.json();
  if (!upstream.ok) {
    return NextResponse.json(payload, { status: upstream.status });
  }

  // Наружу уходит только пользователь. Токены остаются на сервере —
  // в этом весь смысл BFF.
  const response = NextResponse.json({ user: payload.user });
  setSessionCookies(response, payload);
  return response;
}
```

`request-code`, `session` и `logout` пишутся по тому же образцу:
проверка происхождения → проксирование → работа с cookie.
