## Суть

**SmartQoldau** — платформа мгновенной онлайн-психологической поддержки для рынка Казахстана. Слоган: «Поддержка рядом, когда она нужна». Ключевое обещание: **от запроса до помощи за 1–2 минуты** — пользователь выбирает тему и формат, система автоматически подбирает свободного верифицированного психолога.

Платформа юридически позиционируется как **посредник** между клиентами и специалистами: не медицинская и не экстренная служба (при угрозе жизни — 102/103), ответственность за содержание консультации несёт специалист, платформа проверяет только квалификацию.

## Ключевые дифференциаторы

1. **Скорость**: автоподбор специалиста за 1–2 минуты вместо очередей на дни/недели.
2. **Анонимность** (против стигмы): вход без регистрации, психолог видит клиента как «Анонимный клиент #1048» — только тему обращения, без имени и контактов.
3. **Экстренный сценарий**: кнопка «Мне нужна помощь сейчас» → приоритетный поиск вне общей очереди, с постоянной кнопкой вызова 103/112 и проверкой угрозы жизни.
4. **Локальность**: казахский + русский (+ английский), валюта ₸, локальные специалисты. Конкуренты (BetterHelp, Talkspace, Headspace/Calm) не закрывают локальный рынок и экстренность.
5. **Три формата**: чат / аудио / видео, сессия ~30–50 минут, шифрование, без записи.

## Персоны

- **Клиент** — человек в стрессе/кризисе; может быть анонимным гостем (история не сохраняется, нет синхронизации) или зарегистрированным (телефон + SMS, Google/Apple). Демо: Уланбек Бакитжанов.
- **Эксперт (психолог)** — верифицированный специалист, сам назначает цену за сессию, управляет расписанием и статусом доступности. Демо: Айгуль Сатпаева (4.9★, 247–312 отзывов, 3 990 ₸/сессия).
- **Платформа/операторы** — верификация документов (ручная, до 24 ч), модерация жалоб и выводов средств, поддержка (SLA «в течение рабочего дня»), команда качества (приватные отзывы).

## Монетизация

1. **Комиссия с консультаций — 15%** (3 990 ₸ − 599 ₸ = 3 391 ₸ эксперту). Цену задаёт эксперт в коридоре 2 000–15 000 ₸ (решение Р-04; в прототипе 3 200–5 490 ₸).
2. **Подписка Premium для клиентов** — 2 990 ₸/мес или 23 900 ₸/год (единая цена, решение Р-08): скидка 10% на консультации за счёт комиссии платформы (Р-03; в прототипе было 25% — пересмотрено как убыточное), приоритетный подбор, безлимит самопомощи. Консультации в подписку не входят.
3. **По Investor Deck также планируются**: подписка психологов, B2B-лицензии, страховые, госпрограммы, образовательные учреждения, партнёрства.

Оплата: привязанная банковская карта, разовая оплата перед сессией («30 минут · 3 990 ₸»). Начисление эксперту — по исходу сессии: «состоялась» → полная сумма; no-show/отмена клиентом/техпроблема → **0 ₸** (компенсаций нет). Вывод средств — с внутреннего баланса на карту, заявки модерируются (статусы: Обрабатывается / Выплачено / Отклонено).

## Основные пользовательские сценарии

**Клиент:**
1. Быстрая помощь: тема (9–11 тем: тревога, депрессия, панические атаки, зависимости, отношения, потеря, самооценка, выгорание…) → формат → автоподбор ≤2 мин → «Специалист найден» → оплата → сессия → оценка (приватный отзыв — только команде качества).
2. Экстренный: «Мне нужна помощь сейчас» → проверка угрозы жизни → приоритетная очередь.
3. Плановый: каталог с фильтрами (специализация, формат, язык, город, цена/рейтинг/опыт) → профиль психолога → запись; избранное, перенос/отмена.
4. Самопомощь (retention + основа Premium): медитации, дыхательные упражнения, музыка, статьи, стрики; экран «Анализ» — пульс/HRV с Apple Watch с проактивным предложением «Подышать / Поговорить».

**Эксперт:**
1. Онбординг: телефон+SMS → анкета (город, опыт, образование, специализации, языки, **своя цена**, форматы) → загрузка 4 документов (удостоверение, диплом, сертификаты, квалификация) → ручная проверка до 24 ч → бейдж «Верифицированный специалист». Есть состояние «Профиль временно заблокирован».
2. Работа: рабочий статус (Принимаю / Занят / Не принимаю / Временно недоступен), входящая заявка с жёстким таймером автоотклонения (20 с в мобильном / 240 с в вебе), экстренные заявки вне очереди (opt-in тумблер), проведение сессии, фиксация исхода, приватные заметки («не используйте медицинские диагнозы»).
3. Финансы: доход в реальном времени, комиссия 15%, баланс, вывод на карту.
4. Репутация: рейтинг, публичные ответы на отзывы, жалобы на отзывы.
