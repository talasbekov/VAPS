# 05 — Определение продукта

Статус: готов · Дата: 2026-09-13 · Основания: [[PRD MVP SmartQoldau]], [[ТЗ MVP SmartQoldau]], [[Описание проекта SmartQoldau]], решения Р-01…Р-27, прототип v2 (`RAW/SmartQoldau (1)`), код.
Связано: [[06_ROLES_AND_PERMISSIONS]], [[07_USER_FLOWS_AND_INFORMATION_ARCHITECTURE]], [[16_RISKS_QUESTIONS_AND_ADRS]].

## 1. Проблема, аудитория, ценность

- **Проблема.** Человеку в Казахстане, которому плохо сейчас, психологическая помощь недоступна: очереди в дни и недели, непрозрачная цена, стигма. [FACT] PRD §1.
- **Для кого.** Клиенты 18+ в РК (ru/kz), в остром состоянии или планирующие работу с психологом; верифицированные психологи-практики; операционная команда платформы.
- **Ключевая ценность.** Соединение с верифицированным специалистом за 1–2 минуты (p90 ≤ 2 мин), полная конфиденциальность (гость без имени; имя — только с явного согласия, Р-27), три формата (чат/аудио/видео), честные деньги (эскроу-холд: не состоялась — 0 ₸ списания).
- **Чем продукт является.** Маркетплейс-посредник C2C с автоподбором и экстренной веткой; агентский договор, платформа удерживает комиссию 15 % (Р-02, Р-07).
- **Чем продукт не является.** Не медицинская и не экстренная служба (дисклеймеры 102/103/112/150 обязательны, ТЗ §4.3); не мессенджер с психологом вне сессии (расхождение №10: «Чаты» вне консультации не делаются); не e2e-шифрованный канал (сервер расшифровывает переписку для участников — [[12_SECURITY_AND_PRIVACY]] §4).

## 2. Happy path и критические unhappy paths

**Happy path (клиент):** открыть приложение → гость → тема → формат → `POST /requests` → оффер эксперту (45 с) → accept → консультация ACTIVE → оплата холдом → чат/аудио/видео 50 мин → эксперт фиксирует «состоялась» → capture, 85 % на баланс эксперта → оценка → «продолжить с тем же» / избранное.

**Unhappy paths (все реализованы в коде, см. [[04_FEATURE_INVENTORY]]):** никто не принял (ротация → `NO_EXPERTS`); экстренная без ответа (broadcast 2 мин → hotlines + callback 5 мин); клиент не подключился 3 мин (`CLIENT_NO_SHOW`, void); техпроблема (`TECH_ISSUE`, void); поздняя отмена плановой (учёт злоупотреблений, 3+ → только ручной выбор); банк отменил холд (`hold_voided_by_bank`); пуш не доставлен (SMS через 10 с); отказ верификации (повторная загрузка одного документа); выплата >300 000 ₸/мес (финконтроль).

## 6. Метрики успеха (из PRD §6, измеримы админкой/PostHog)

Опережающие: запрос→соединение p90 ≤ 2 мин; подбор→оплата ≥ 40 %; принято с первого эксперта ≥ 60 %; «состоялась» ≥ 85 %; пуш ≤ 3 с p95 ≥ 99 %. Запаздывающие (90 дней): ≥ 500 оплаченных консультаций; повтор в 30 дней ≥ 30 %; ≥ 60 активных экспертов; отток экспертов ≤ 20 %; Premium ≥ 5 % MAU через 30 дней после R2.
