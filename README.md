Проект **VAPS** — это веб-система для автоматизации кадрового учёта, управления организационной структурой, штатным расписанием и ежедневным расходом личного состава.

Система позволяет вести сотрудников, подразделения, штатные единицы, вакансии, статусы сотрудников, прикомандирования, отчёты, уведомления и аудит действий пользователей. Основная цель проекта — заменить ручной учёт и формирование документов единой цифровой системой с ролевым доступом, автоматическими статусами, генерацией отчётов в DOCX/XLSX/PDF и контролем изменений.

Технологически проект строится на **Django REST Framework + PostgreSQL** для backend и **Vite + React + TypeScript** для frontend. Next.js/Nuxt/Remix рассмотрены и отклонены: SSR и CDN бесполезны в закрытом LAN-контуре (см. ADR в `_bmad-output/planning-artifacts/architecture.md`, «Selected Starter»).

Для фоновых задач, real-time уведомлений и авторизации запланированы **Celery, Redis, WebSocket (Django Channels) и JWT** — они относятся к эпикам 11 (уведомления) и 12 (деплой в контур) и в кодовой базе пока не появились. Актуальное состояние: backend (`Backend/VAPS`) — контексты `core` и `operations`; frontend ещё не сформирован (эпик 8).
