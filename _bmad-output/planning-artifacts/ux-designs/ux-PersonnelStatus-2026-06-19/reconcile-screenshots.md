- Ряд **KPI-плиток** со счётчиками по статусам: По штату 124 · Всего сотрудников 120 · Вакансии 4 · Всего отсутствуют 19 · Отпуск 8 (красный) · Отпуск по рапорту · Больничные 4 (красный) · Командировка 0 · Учёба 0 · Соревнования 0 · Иные 0 · На дежурстве 7 · После дежурства 0 · Прикомандирован 0 · Откомандирован 0. Числа цветные.
- Блок **«Структура организации»**: горизонтальное оргдерево по заместителям/департаментам, под каждым — **карточки сотрудников с аватарами** (фото), в сетке. Одна карточка подсвечена красным (скрин 2).
- Эстетика: скруглённые карточки, мягкие тени, воздух, цветные иконки.

**«Управление персоналом» (скрин 3):**
- Шапка «Управление персоналом» + подзаголовок; кнопки «10 сотрудников», «Обновить», синяя «Добавить сотрудника».
- 4 **KPI-карточки** с цветными иконками: Всего сотрудников 10 (синий) · В строю 10 (зелёный) · В отпуске/больничном 0 (жёлтый календарь) · В командировке 0 (фиолетовый телефон).
- Табы **«Список сотрудников» / «Карточки»**; кнопки «Импорт» / «Экспорт».
- Поиск «Поиск по ФИО, должности, отделу…» + фильтры «Все отделы», «Все статусы».
- **Таблица**: № · ФИО · Должность · Отдел · Контакты (иконки) · Дата найма · ⋯. Аватаров в таблице нет, но есть в табе «Карточки».

## Что в спайнах эталон НЕ отменяет (поведенческое ядро, на скринах не показано)

- Клавиатурный слепой ввод (Enter↓/Tab→/Esc, преднабор «вчера»).
- Семантика конфликтов 409 soft / 422 hard + ConflictDialog.
- Гейт ФИНАЛ-расхода + список отстающих + async .docx.
- Светофор-каскад готовности листов.
- RBAC scope-gating, маскировка ИИН, аудит.

→ Эти скриншоты задают **визуальный язык и часть IA** (дашборд-first, KPI-плитки, оргструктура-с-аватарами, тёплый тон), но не отменяют поведенческую глубину спайна.
