2. **AC-2 · `deploy/scripts/deploy-rehearsal.sh` (NEW) — интерактивный проводник по чеклисту.** Шаги скрипта = секции B–C чеклиста (подготовка A — по флагу `--first-time` добавляется в начало). На каждом шаге печатает пункт и ждёт ответа: `y` (выполнено), `n` (провал — репетиция останавливается с ненулевым exit, недойденные шаги пишутся в лог как NOT-REACHED), `s <причина>` (пропуск ТОЛЬКО с непустой причиной — пустая отклоняется и вопрос повторяется). Никакого «Enter = да»: пустой ввод переспрашивает. Скрипт НЕ исполняет команды за оператора (репетиция ПРОЦЕДУРЫ: человек делает руками, скрипт ведёт и хронометрирует) — это решение №1.
3. **AC-3 · Лог шагов с временем (epic-буква).** `INSTALL_DIR/rehearsals/deploy-rehearsal-<UTC-ts>.log`: строка на шаг — UTC-время ответа, длительность шага в секундах, номер+название, вердикт (OK/SKIP+причина/FAIL/NOT-REACHED), плюс шапка (кто проводит — спрашивается на старте, тег) и итог (общая длительность, счётчики OK/SKIP/FAIL). Лог пишется ПО ХОДУ (append после каждого ответа), а не в конце: прерванная репетиция оставляет честный частичный журнал.
4. **AC-4 · «Заполняется без пропусков» (epic-буква).** Итоговый вердикт скрипта: `REHEARSAL OK` — только если ВСЕ шаги `y`; при наличии `s` — `REHEARSAL INCOMPLETE (N skipped)` + перечень пропущенных с причинами, ненулевой exit; при `n` — `REHEARSAL FAIL` на шаге X, ненулевой exit. Сводка дублируется на stdout и в лог.
5. **AC-5 · `make deploy-rehearsal` (Backend/VAPS/Makefile, M — одна цель).** Архитектурная таблица #L643: цель зовёт `bash ../../deploy/scripts/deploy-rehearsal.sh` (интерактивно, без завязки на venv/Django). В help-комментарии — «ручная, интерактивная».
6. **AC-6 · Инварианты качества + красные пробы.** Скрипт: `set -Eeuo pipefail`, кавычки, `bash -n` чист; работает из INSTALL_DIR-модели 12.3 (дефолт — каталог скрипта; но НЕ требует .env — репетиция возможна до его доставки). Пробы: (1) 🔴 пропуск без причины (`s` и `s ` с пробелом) → отклонён, вопрос повторён; (2) 🔴 `n` на середине → FAIL, недойденные шаги в логе NOT-REACHED, exit≠0; (3) прерывание (Ctrl-C/kill) посреди репетиции → частичный лог существует и валиден, строка INTERRUPTED; (4) полный `y`-прогон → REHEARSAL OK, длительности шагов в логе ненулевые и суммируются в итог; (5) `s причина` → INCOMPLETE, причина в логе, exit≠0.
7. **AC-7 · Синхронизация чеклист↔скрипт защищена.** Шаги в скрипте определены ОДНИМ массивом с ID вида `B1`,`C3`; те же ID проставлены в CHECKLIST.md у пунктов. В шапках обоих файлов — пометка «правки синхронно» (перекрёстная ссылка). Отдельного авто-теста не строим (Решение №3) — пары ID сверяются глазами ревью.
8. **AC-8 · Гейт зелёный + deferred-обновление.** `make gate` 2491/56 (Python не тронут — цифра та же); `makemigrations` пуст. deferred-work:678 помечается: CHECKLIST-строка закрыта здесь, decision «паковать в бандл» остаётся открытым за Bratan.

### Решения (Bratan-overridable)

- **Решение №1:** deploy-rehearsal НЕ исполняет команды за оператора — только ведёт, требует ответа и хронометрирует. Исполняющий вариант превратил бы репетицию процедуры в автоматизацию (и потребовал бы живой стек+носитель в CI, которых нет); реальный исполненный прогон = 12.7.

- **Решение №3:** синхронизация чеклист↔скрипт — ID-пары + пометки «правки синхронно», без авто-теста (два файла в одном каталоге, меняются вместе; тест на парсинг markdown — хрупкость дороже пользы).
- **Решение №4:** лог — в `INSTALL_DIR/rehearsals/`, отдельно от `backups/` (ротация бэкапов не имеет права трогать журналы репетиций; репетиции не ротируются — бумажный след копится).

### Ловушки

- Пустой ввод / EOF в `read -r` под `set -e` — обязателен guard, иначе бесконечный цикл или тихая смерть.
- INT/TERM-trap пишет INTERRUPTED и выходит СВОИМ кодом (130/143) — EXIT-сводка «OK» не должна печататься поверх прерывания.
- Все упоминания запуска в CHECKLIST — `bash script.sh` (носитель FAT/exFAT теряет exec-биты, урок 12.3).
- ARCH-SEC-030: в чеклисте нет ни одного секретного литерала — только «☐ .env доставлен отдельно и заполнен по .env.example».
