# Story 9.9: E2E слепого ввода

Status: review

## Story

As a **оператор**,
I want **Playwright-сценарий в реальном chromium: слепой ввод 20 строк ТОЛЬКО клавиатурой в грид на прод-сборке — с реальной виртуализацией, реальным скроллом, реальной модальностью конфликт-диалога и перф-трендом под CDP-троттлингом**,
so that **всё, что jsdom физически не может доказать (скролл-каскад, showModal, браузерная виртуализация, p95), проверено в браузере до подключения экрана 10.2**.

## Scope

E2e-харнес-страница (отдельная Vite-сборка `dist-e2e`, НЕ прод-бандл): `DailyGridContainer` на 500 строках + счёт коммитов через DevTools-hook + `window.__e2e`-хуки. Playwright-спеки: (1) слепой ввод 20 строк только клавиатурой → bulk-3.8-payload РОВНО соответствует вводу; (2) браузерная виртуализация при вводе/скролле; (3) модальность ConflictDialog (deferred 9.5); (4) перф-артефакт p95/commits-per-key под CDP CPU-троттлингом (deferred 9.8, НЕ блокирующий) + факт навигационного каскада (закрывает PENDING спайка 1.10).

## Out of Scope

- **«Статусы в БД»** — недостижимо до 10.2: bulk-роута НЕТ в schema.d.ts (E10), роута грида НЕТ в App (10.2), compose содержит только `db` (полный стек = E12/13). 9.9 доказывает браузерную половину канонического сценария №2 (L259) через payload-ассерт; дорастание до «→БД» — при 10.2 (Q2). Временный бэкенд-роут/правку schema.d.ts НЕ городить (schema-check гейт).
- Прод-код грида/грамматики/контейнера НЕ менять. Роут в App.tsx НЕ добавлять (10.2). Блокирующий тайминг-ассерт НЕ вводить (L246). Целевой прогон FF100/4ГБ — ручной, за Bratan (BUDGET.md §2). Клавиатурный ВЫХОД из грида (Tab-ловушка) — НЕ чинить здесь: продуктовое решение за Bratan, вход 10.2 (см. Ловушку №6).

## Acceptance Criteria

1. **Слепой ввод 20 строк → payload соответствует вводу.** Given харнес (прод-сборка, 500 строк, грид сам фокусирует ячейку на маунте), When оператор заполняет строки 0-19 ТОЛЬКО клавиатурой (кириллический type-ahead статусов, ISO-период у ≥3 строк, навигация Enter/стрелки — ни одного mouse-действия В ГРИДЕ; каждый ввод ОТЛИЧАЕТСЯ от prefill-значения строки, иначе строка не dirty и в payload не попадёт), and «Сдать день» активируется БЕЗ мыши в гриде (кнопка ВНЕ грида — программный `locator.focus()`+Enter законен по букве epics-AC; Tab из грида не выводит — Ловушка №6), Then `window.__e2e.lastBulkRequest` = bulk-3.8-запрос РОВНО с 20 введёнными строками (employee_id/status_type_code/date_start/date_end по контракту 9.7: date_start=businessDate, ISO-период «включительно» → date_end=период+1д).

2. **Браузерная виртуализация.** Given ввод пересекает границу окна (реальный `scrollToIndex`/скролл; `h-96`=384px, ROW_HEIGHT=36, OVERSCAN=8 → ⌈384/36⌉+2·8+пин ≈ 29 узлов), Then в ЛЮБОЙ момент серии `[data-grid-row]` ≤ 34 (расчётная граница, не магическое число — прецедент ревью 9.8 P3) и ≪ 500; строки, ушедшие за окно, анмаунтятся (ассерт по НЕфокусной строке — сфокусированную пинит rangeExtractor 9.5).

3. **Модальность ConflictDialog (deferred 9.5).** Given харнес-фикстура: коммит строки-маркера ВНЕ диапазона AC1 (e42) возвращает soft-`ConflictError` (код из `OVERRIDABLE_CODES`, напр. `SOFT_CONFLICT_DETECTED` — `overridable` выводится из кода, НЕ параметр), When оператор коммитит эту строку, Then диалог открыт реальным `showModal`: фокус ВНУТРИ диалога, фон inert (клавиши мимо диалога грид не меняют), Esc = «Отмена»: значение откатилось к pre-edit, **soft-маркер ОСТАЁТСЯ** (семантика 9.6 AC-3 — снимает маркер только «Подтвердить оверрайд»). Это то, что jsdom-полифилл 9.5 доказать не мог.

4. **Перф-артефакт (deferred 9.8, НЕ блокирующий) + факт каскада.** Given CDP CPU-троттлинг (×4), When серия ≥100 нажатий (правки + навигация через окно), Then в `test-results/perf-trend.json` пишутся p95/max keydown→commit, max commits-per-key и DOM-строки (+метаданные окружения); блокирующе ассертится ТОЛЬКО детерминированный инвариант «edit-keystroke = 1 коммит»; фактическое число навигационного каскада фиксируется в артефакте (закрывает PENDING-перепрогон спайка §7), блок-порог НЕ назначается (Q1). Счёт коммитов — ТОЛЬКО через DevTools-hook (Ловушка №1), commits-per-key вне latency-гарда.

5. **Гейт, границы, регресс.** `npm run gate` зелёный и НЕ включает e2e (офлайн-контур 8.8); `npm run test:e2e` зелёный локально; прод-`dist/` и size-gate не изменились (харнес — отдельная сборка `dist-e2e`, добавлена в .gitignore); прод-код daily-grid/grammar/App не тронут; тесты 9.2-9.8 без регресса.

## Dev Notes

### ⚠️ Ловушка №1 (ГЛАВНАЯ): считать коммиты на прод-сборке можно ТОЛЬКО DevTools-hook'ом

E2e идёт против ПРОД-сборки (канон 8.8). Два нерабочих пути, оба уже наступали: `<Profiler onRender>` — но-оп в прод-react-dom (спайк 1.10 §6.2, проверено); `useLayoutEffect`-тик в харнес-обёртке видит только ре-рендеры ХАРНЕСА — setState внутри DailyGrid родителя не трогает (аппарат спайка жил ВНУТРИ компонента — сюда не переносится). Рабочий механизм: стаб `__REACT_DEVTOOLS_GLOBAL_HOOK__.onCommitFiberRoot` inline-скриптом ДО бандла (Task 1). Commits-per-key — на каждом коммите вне latency-гарда, иначе async-коммит `scrollToIndex` невидим (§6.5 — эта слепота чинилась уже дважды: спайк D1, ревью 9.8 P2).

### ⚠️ Ловушка №2: «→БД» — НЕ в этой стори

Полный канонический сценарий L259 требует: bulk-роут (в schema.d.ts НЕТ — E10), роут/экран грида (10.2), полный compose (сейчас только `db`). 9.9 доказывает браузерную половину + контракт payload; «→БД» дорастает в 10.2 БЕЗ выбрасывания этих спеков. НЕ трогать schema.d.ts (schema-check упадёт), НЕ добавлять роут в App.tsx.

### ⚠️ Ловушка №3: харнес не должен коснуться прод-бандла

size-gate суммирует ВСЕ JS в `dist/`; грид сейчас тришейкнут из прод-бандла (не импортируется из App) — второй вход в той же сборке втащил бы его в бюджет. Отдельный конфиг → `dist-e2e/`, свой preview-порт, `.gitignore`. Прод-`dist/` байт-в-байт как был.

### ⚠️ Ловушка №4: кириллица — и в пути, и в сидах

Путь репо кириллический → только `fileURLToPath` (инцидент 8.8). Type-ahead матчится `toLocaleLowerCase('ru')` по лейблам — сиды ТОЛЬКО кириллические с разными префиксами, латиница молча не матчится (ревью 9.8 P1 — серия была вакуумной).

### ⚠️ Ловушка №5: e2e вне gate; блокирующее — только детерминированное

Гейт офлайн-контура без Playwright-браузеров (Д4 8.8) — e2e отдельной командой. Блокирующи только детерминированные факты (payload, DOM-бюджет, модальность, edit=1 коммит); тайминги и навигационный каскад — артефакт-тренд (L246; блок-порог каскада — ПОСЛЕ первого факта, Q1).

### ⚠️ Ловушка №6: Tab-ловушка — «Сдать день» из грида клавиатурой НЕДОСТИЖИМА (deferred 9.4, узаконено здесь)

Грамматика клампит Tab/Shift+Tab на границах строки (MOVE + preventDefault) — Tab НИКОГДА не покидает грид; кнопка «Сдать день» стоит ВЫШЕ грида. Ревью 9.4 предупредило: «e2e 9.9 столкнётся первым» — столкнулись. Букву epics-AC («без единого клика мыши В ГРИДЕ») это не ломает: кнопка вне грида, спек активирует её программным `locator.focus()`+Enter. Санкционированный клавиатурный ВЫХОД из грида — продуктовое решение (бумажный контракт §3.2, Bratan) → вход 10.2 (Q4); прод-код здесь не менять.
