# Story 9.8: Перф-смоук грида

Status: review

## Story

As a **разработчик**,
I want **блокирующий перф-смоук грида в Vitest: на 500 строках серия нажатий даёт РОВНО 1 React-коммит на нажатие (детерминированный счётчик, без каскада) и число DOM-узлов в бюджете виртуализации; плюс не-блокирующий артефакт тренда p95 keydown→commit (Playwright CDP throttling)**,
so that **перф-деградация ловится до пользователя (блокирующе), а тренд таймингов виден без флейка гейта**.

## Scope

Блокирующий Vitest перф-смоук: 500 строк, серия символов → commits==нажатия + ≤N DOM. Не-блокирующий p95-тренд (Playwright CDP) — привязывается к смонтированному гриду (роут = 9.9/10.2); здесь документируется + бюджет спайка 1.10.

## Out of Scope

- **Playwright p95 CDP-прогон против живого экрана** → требует роут/страницу грида (9.9/10.2); 9.8 даёт блокирующую Vitest-часть + документирует p95-артефакт как не-блокирующий (привязка при монтировании грида). e2e слепого ввода → 9.9. grammar/грид/фокус/валидация (9.2-9.7) не менять.

## Acceptance Criteria

1. **Блокирующий счётчик коммитов на серии (500 строк).** Given грид с 500 строками в `<Profiler>`, When фиксируется серия из N нажатий (ввод символов), Then число React-коммитов == N (РОВНО 1 на нажатие, без каскада); тест БЛОКИРУЮЩИЙ (commits≠N → красный).

2. **Блокирующий DOM-бюджет при 500 строк.** Given 500 строк, Then число DOM-узлов строк (`[data-grid-row]`) ≤ N-бюджет (виртуализация; N из спайка 1.10, константа 60 как в 9.4), не 500.

3. **p95-тренд (не блокирующий, артефакт).** Given серия keydown→commit, Then p95 таймингов пишется в артефакт (Playwright CDP CPU-throttling) — НЕ блокирует гейт (architecture L246). ⚠️ Требует смонтированный грид (роут) → привязка при 9.9/10.2; в 9.8 — документ + бюджет-ссылка (спайк 1.10), без блокирующего прогона.

4. **Гейт, регресс.** `npm run gate` зелёный (перф-смоук в vitest); перф 9.4 / фокус 9.5 / валидация 9.6 / prefill 9.7 без регресса. grammar.ts не тронут.

## Dev Notes

### ⚠️ Ловушка №1 (ГЛАВНАЯ): счётчики ДЕТЕРМИНИРОВАННЫЕ, тайминги — тренд

architecture.md L246: блокирующие перф-инварианты = СЧЁТЧИКИ (Profiler-коммиты, DOM-узлы), НЕ тайминги. p95 keydown→commit — только тренд-артефакт (Playwright CDP), НЕ блокирующий (иначе флейк на CI, урок tz-флейка). 9.8 блокирует счётчики, тайминг — артефакт.

### ⚠️ Ловушка №2: серия без скролл-каскада → commits==нажатия

На 500 строк ArrowDown уводит фокус из окна → scrollToIndex → виртуализатор ре-рендерит (лишний коммит). Чтобы «1 коммит на нажатие» держался детерминированно, серия — символы В ОДНОЙ ячейке (TYPE_AHEAD: NAVIGATE+Char→open+1 commit, EDIT+Char→stay+1 commit; setFocus новый объект → всегда 1 re-render, без скролла). Тогда commits==число символов. (Скролл-индуцированный коммит — отдельная забота виртуализатора, не инвариант «1/keystroke».)

### ⚠️ Ловушка №3: p95 Playwright требует роут грида

Грид не смонтирован в странице (роут = 10.2). Playwright CDP p95 нельзя прогнать без страницы → 9.8 документирует p95-артефакт как не-блокирующий, привязка — при 9.9 (e2e) / 10.2 (экран). Блокирующая Vitest-часть (счётчики) — полноценно сейчас.

### ⚠️ Ловушка №4: не сломать 9.4-9.7

Перф-смоук — только тест (0 прод-кода). Грид/грамматика/контейнер не меняются; их тесты в гейте зелёные.
