## Story

As a **оператор/руководство с правом `daily_report.generate`** (epics-персона «оператор»),
I want **print-route на голом семантическом HTML по контракту секции 77 (шапка «ЖЕКЕ ҚҰРАМЫНЫҢ САПТЫҚ ТІЗІМІ», канонический порядок и лейблы колонок, жирный ИТОГО) для контрольной печати расхода через Ctrl+P**,
so that **быстрая контрольная печать не зависит от .docx-канала — официальный документ остаётся .docx с бэка (6.3/6.5), print-route его НЕ заменяет**.

## Goal

Первая **реальная** печатная форма в печатном каркасе 8.8 (до сих пор в слоте `features/print-forms` жила только тест-страница `PrintTestPage`). Роут `/print/expense?division_id=<uuid>&date=<iso>` рендерит контрольную (числовую) версию таблицы секции 77 из **уже существующего** read-only эндпоинта `GET /api/operations/expense-reports/period/` (6.10a, single-date запрос `date_from=date_to=date`). Бэкенд НЕ трогается: ни новых эндпоинтов, ни изменения схемы — стори чисто фронтовая.
