# Story 9.6: Валидация в гриде

Status: review

## Story

As a **оператор**,
I want **zod-валидацию строки при коммите и конфликт-маркеры по строкам — soft (409 overridable → жёлтый warning + ConflictDialog с оверрайдом) и hard (422 / zod-невалид → красная заливка строки, коммит блокируется, оверрайда нет) — с маппингом ошибок бэка на конкретные строки**,
so that **ошибка видна ИМЕННО там, где возникла; блокируется только проблемная строка, остальные редактируемы**.

## Scope

Расширить seam 9.5 `onCellCommit` до `ApiError|null` (soft/hard); zod-схема строки; per-row маркеры (soft/hard/invalid) + рендер (флаг-колонка + заливка строки); soft→ConflictDialog+override (9.5), hard→блок без диалога.

## Out of Scope

- **Prefill «вчера» + отправка-дельт через bulk-3.8** → 9.7 (9.6 маппит ошибки per-cell через seam; мульти-строчный bulk-ответ подключит 9.7). e2e → 9.9; экран/роут/реальные сетевые вызовы → 10.2. grammar.ts (9.2) не меняется; перф (9.4)/фокус (9.5) не ломать.

## Acceptance Criteria

1. **Seam расширен до ApiError.** Given `onCellCommit?: (change) => ApiError | null`, Then грид ветвит: `ConflictError` с `overridable===true` → **soft**; `BusinessRuleError` (422) или non-overridable → **hard**; `null` → нет конфликта.

2. **zod-валидация строки.** Given коммит ячейки, When строка не проходит zod-схему (напр. пустой `statusCode`), Then маркер `invalid` (как hard — красный, коммит блокируется), фокус остаётся на ячейке; ошибка — на этой строке.

3. **soft (409 overridable) — жёлтый + оверрайд.** Given `onCellCommit` вернул overridable `ConflictError`, Then строка помечена soft (жёлтый маркер во флаг-колонке + жёлтая подсветка), открыт `ConflictDialog`; «Подтвердить оверрайд» → маркер снят, коммит проходит (retry override:true — контракт 9.7-bulk); «Отмена» → маркер остаётся, фокус в ячейке (9.5).

4. **hard (422 / non-overridable) — красный блок, БЕЗ диалога.** Given `onCellCommit` вернул `BusinessRuleError` (или non-overridable), Then строка помечена hard (красная заливка + маркер), коммит БЛОКИРУЕТСЯ, диалог НЕ открывается, оверрайда нет, фокус на ячейке.

5. **Маппинг на строки; остальные редактируемы.** Given маркер на строке, Then он привязан к её `rowId` (не глобален); другие строки навигируемы/редактируемы; исправление значения строки снимает `invalid`-маркер при следующем валидном коммите.

6. **Гейт, границы, регресс.** `npm run gate` зелёный. grammar.ts (9.2) НЕ изменён; перф-инвариант 9.4 (1 commit/keystroke) и фокус-инварианты 9.5 сохранены (их тесты зелёные). ARCH-FE-014 (conflict-токены/Tailwind, без runtime CSS-in-JS; красная заливка 422 — отдельный слой, не статус-цвет). boundaries/lint-canon чисты.

## Dev Notes

### ⚠️ Ловушка №1 (ГЛАВНАЯ): деление hard/soft из ТИПА ошибки, не зашито в UI

Контракт §5: «деление hard/soft конфигурируется при деплое — UI не зашивает». Источник — БЭКЕНД (E3: 409 overridable-код ⟺ soft, 422 ⟺ hard). Грид ветвит по `ApiError`: `ConflictError.overridable===true`→soft; `BusinessRuleError`/non-overridable→hard. НЕ хардкодить список статусов/пар в UI (ARCH-FE-015 + error-codes-реестр — знание бэка).

### ⚠️ Ловушка №2: hard/invalid БЛОКИРУЕТ (коммит не проходит), soft — оверрайдаем

Hard (422/zod-невалид): красная заливка, коммит БЛОКИРУЕТСЯ, диалог НЕ открывается, оверрайда нет (контракт §5). Soft (409 overridable): жёлтый + ConflictDialog (9.5) + «Подтвердить оверрайд»→снять+пройти. Не путать: 422≠409; красная заливка = отдельный конфликт-слой, НЕ статус-цвет (§4/DESIGN).

### ⚠️ Ловушка №3: маркеры per-row — не блокировать весь грид

AC-5: маркер привязан к `rowId`; блокируется ТОЛЬКО проблемная строка, остальные навигируемы/редактируемы. `Record<rowId, RowMarker>`, не глобальный флаг. «409 с детализацией по строкам» → маркеры на соответствующих rowId (per-cell seam маппит текущую строку; мульти-строчный bulk-ответ = 9.7).

### ⚠️ Ловушка №4: не сломать 9.4/9.5 (перф + фокус)

Маркеры — лёгкое per-row состояние (мемоизация GridRow: маркер в пропсах строки, ре-рендерит только затронутую). Перф-инвариант 1-commit/keystroke (9.4) и фокус-инварианты (9.5) обязаны остаться зелёными — их тесты в гейте. Красная заливка/маркер — className/токен, без extra-setState в эффектах.

### ⚠️ Ловушка №5: grammar 9.2 заморожена; soft-путь = 9.5

Грамматика не меняется. Soft переиспользует CONFLICT-режим + ConflictDialog + фокус-возврат 9.5. 9.6 добавляет ВЕТВЛЕНИЕ (soft/hard/invalid) и МАРКЕРЫ поверх seam.
