# Story 10.8a: UI кнопка «моя копия»

Status: ready-for-dev

## Story

As a **оператор**,
I want **кнопку «Моя копия» на панели сдачи дня, скачивающую личный .xlsx-экспорт СДАННОЙ версии**,
so that **у меня есть доказательство сдачи на руках, а не только в системе (эпик-AC 10.8 «щит»), и я не завишу от бэкенд-роута, до которого нет пути из интерфейса**.

## Acceptance Criteria

Источник: `_bmad-output/implementation-artifacts/sprint-status.yaml:457-467` («10.8a — ФРОНТ: кнопка «моя копия» в DaySubmissionPanel под current !== null, apiClient.getBlob + ЛОКАЛЬНЫЙ saveBlob (импорт из features/expense запрещён ARCH-FE-013), useApiMutation (сырой useMutation в features/** забанен), 403/404/422, RTL + Playwright-ассерт БАЙТОВ»).

1. **AC-1 (кнопка видна только на сданном дне).** Given `current !== null` (день сдан — та же производная, что уже держит блок «День сдан»/кнопку «Исправить сдачу», `DaySubmissionPanel.tsx:218`), Then кнопка «Моя копия» видна. Given `current === null`, Then кнопки нет вовсе.
2. **AC-2 (скачивание — ВЕРСИЯ, не «сегодняшняя точка»).** Клик зовёт `GET /api/operations/daily-submissions/{current.id}/export/` — `{id}` берётся из ТЕКУЩЕГО отображаемого `current` (той же версии, что показана в блоке «День сдан: v{N}»), НЕ из пересчитанного «последнего id». Роут уже существует (Story 10.8, done), эта стори НЕ трогает бэкенд.
3. **AC-3 (файл сохраняется через `saveBlob`, ЛОКАЛЬНУЮ копию — ARCH-FE-013).** Импорт `saveBlob` из `features/expense/ExpenseReportPage.tsx` ЗАПРЕЩЁН (`features/A → features/B`, ARCH-FE-013). Новая ЛОКАЛЬНАЯ копия функции — в `features/daily-grid/` (дублирование ~10 строк дешевле нарушения границы фичи; прецедент решения №1 стори 10.3 «панель лежит ВНУТРИ daily-grid»). Имя файла — из `Content-Disposition` сервера (`filename*=UTF-8''<pct>`), фолбэк — `сдача_{business_date}_v{version}.xlsx` (зеркало `personal_export_service.py:104-106`), если сервер не прислал распознаваемое имя.
4. **AC-4 (403/404/422 — инлайн-текст, зеркало `describeDownloadFailure`).** 403 (нет `daily_report.mark_update` на подразделение — не должно быть достижимо штатно, т.к. право уже держит саму панель, но защитный текст всё равно нужен): явный текст, НЕ молчание (тот же довод, что `describeDownloadFailure`'s комментарий про «живой разрыв OMD»). 404 (версия исчезла между рендером и кликом — гонка): «Версия сдачи не найдена.». 422 (`SNAPSHOT_SCHEMA_UNSUPPORTED` — неподдерживаемая версия схемы снапшота): текст конверта. 5xx/сеть/401 — МОЛЧАТ (уже обслужены тостом `useApiMutation`, дубль хуже молчания) — та же карта, что `describeDownloadFailure`, ЗЕРКАЛО, не импорт (та же ARCH-FE-013-граница).
5. **AC-5 (кнопка — `useApiMutation`, НЕ сырой `useMutation`).** ARCH-FE-015: сырой `useMutation` в `features/**` — eslint error. `mutationFn` — `async () => { const {blob, filename} = await apiClient.getBlob(...); saveBlob(blob, filename ?? fallback) }`, зеркало `ExpenseReportPage.tsx:277-287`.
6. **AC-6 (RTL — байты мутации, не факт клика).** Component-тест мокает `apiClient.getBlob` (или MSW-хендлер роута с бинарным телом) и ассертит, что `URL.createObjectURL`/`anchor.click()` вызваны с ОЖИДАЕМЫМИ байтами/именем — не просто «кнопка не упала». Playwright e2e (10.10-класс, если инфраструктура уже собирает `download`-событие) — ВНЕ обязательного скоупа этой стори, если существующая e2e-инфраструктура не даёт готового `download`-ассерта; RTL-уровня достаточно для AC-6, Playwright — опционально, задокументировать решение явно.
7. **AC-7 (регресс нулевой, границы фич соблюдены).** `ExpenseReportPage.tsx`/`expense.ts` — НЕ импортируются, НЕ модифицируются (кроме, возможно, экспорта `saveBlob`, если решено вынести в `shared/` — см. Dev Notes про альтернативу). `npm run gate` зелёный.

## Dev Notes

- **Бэкенд уже готов целиком (Story 10.8, done) — эта стори строго frontend-only.** `GET /api/operations/daily-submissions/{id}/export/` (`views.py:246-275`) — существующий роут, `READ_PERMISSION`-гейт (`daily_report.mark_update`, тот же, что уже держит всю панель через `retrieve`/`list`), `Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `Content-Disposition` через `content_disposition_header`. File List этой стори НЕ включает файлов `Backend/VAPS/`.
- **`apiClient.getBlob` УЖЕ существует — новый транспортный код не нужен.** `shared/api/client.ts:37,110-129` — `getBlob(path): Promise<{blob: Blob, filename: string | null}>`, ошибки идут через ТОТ ЖЕ `ApiError`/`ApiFailure`, что `.get`/`.post` — `useApiMutation`+`describeXFailure`-паттерн работает без изменений.
- **`saveBlob` — ЛОКАЛЬНАЯ копия, не импорт, не вынос в `shared/`.** Существующая реализация — модуль-приватная функция в `ExpenseReportPage.tsx:98-107` (не экспортирована). Cross-feature импорт запрещён ARCH-FE-013 в любом случае. Альтернатива «вынести в `shared/lib/`» РАССМОТРЕНА и ОТКЛОНЕНА для этой стори: рефакторинг существующего `expense`-кода — риск регресса на уже стабильной фиче ради экономии ~10 строк; дублирование — дешевле и безопаснее (тот же принцип, что решение №1 стори 10.3 «панель лежит ВНУТРИ фичи»). Если третий потребитель появится в будущем — тогда вынос в `shared/` оправдан, не раньше.
- **Кнопка скачивает ВЕРСИЮ, не «сегодняшнюю точку».** `current = amended ?? submitted ?? submission` (`DaySubmissionPanel.tsx:218`) — та же переменная, что уже используется для блока «День сдан» и кнопки «Исправить сдачу» (Д1 5.8b: цепочка амендментов). Экспорт «щита» имеет смысл ИМЕННО для конкретной версии — доказательство «я сдал ИМЕННО ЭТО» (тот же принцип, что `export`-роут v6.10a: «экспортируется ЗАПРОШЕННАЯ версия, stale или current — голова цепочки не подставляется»).
- **403/404/422 — редкие, но НЕ невозможные пути, текст обязателен (не молчание).** 403 штатно недостижим (право уже гейтит саму панель), но остаётся защитным путём (роль могла измениться между загрузкой панели и кликом). 404 — реальная гонка (версия исчезла/сменилась между рендером и кликом, хотя в v1-домене это маловероятно). 422 `SNAPSHOT_SCHEMA_UNSUPPORTED` — тот же гвард, что у выпуска расхода (`_assert_snapshot_schema_supported`, `personal_export_service.py:60-75`).
- **Playwright — опционально, не блокирующий гейт этой стори.** Sprint-status формулирует «RTL + Playwright-ассерт БАЙТОВ» как желаемое покрытие, но если существующая e2e-инфраструктура не даёт готового способа перехватить `download`-событие браузера для .xlsx (нужно проверить `Backend/VAPS`/`frontend/e2e/` на наличие такого прецедента ДО начала Task 4), RTL-уровня (мок `saveBlob`/`getBlob`) достаточно для закрытия AC-6 — задокументировать решение явно в Completion Notes, не молчать о пропущенном Playwright-слое.
