## Story

As a **оператор**,

## Acceptance Criteria

1. **AC-1 (реальный запрос вместо `CLOSED_FIXES`-дефолта).** Новый хук (зеркалит `useNotificationsFeed.ts`'s паттерн) вызывает `GET /api/bugreports/journal/` через `apiClient`+`useQuery` (`['bugreports-journal']`), типизирован по сгенерированному `components['schemas']['BugReportJournalEntry']` (`npm run generate:api` уже перегенерирован 13.4a's эндпоинтами — структурно совпадает с `FixEntry` поле-в-поле, ручного маппинга не требуется).
2. **AC-2 (конверт пагинации распакован — КРИТИЧНО, находка 13.4a-ревью).** Бэк отдаёт `{count, next, previous, results}` (`BugReportPagination`, `LimitOffsetPagination`), а `ChangelogPage`'s `fixes`-проп и `changelog.ts`'s `FixEntry[]`/`CLOSED_FIXES` — ГОЛЫЙ массив, без конверта (13.4a's Edge Case Hunter явно зафиксировал это расхождение как landmine для этой стори). Хук распаковывает `.results` ДО передачи в `ChangelogPage`, не выше.
3. **AC-3 (`ChangelogPage.tsx` НЕ трогается).** Компонент уже принимает `fixes`-проп как точку инъекции (10.9's Решение №4, «шов, не украшение») — эта стори подключает контейнер/хук СНАРУЖИ, не переписывает саму страницу. `ChangelogPage.test.tsx`'s существующие тесты (prop-driven) остаются нетронутыми и зелёными.
4. **AC-4 (маршрут — новый контейнер, не голая `ChangelogPage`).** `App.tsx`'s `<Route path={ROUTES.changelog} element={<ChangelogPage />} />` заменяется на новый тонкий контейнер (зеркалит `DailyGridContainer.tsx`'s паттерн — «тонкий: данные/эндпоинт снаружи»), который вызывает хук и передаёт `fixes={data}`.
5. **AC-5 (ошибка/загрузка — не молчаливый пустой список).** Пока запрос летит — `ChangelogPage`'s УЖЕ существующее пустое состояние временно видно (не путать с «исправлений правда нет» — расхождение приемлемо на секунды загрузки, doc'd явно, не скрыто). Ошибка запроса — НЕ тихо превращается в пустой список: видимый признак ошибки (минимум — тот же `useToast`'s глобальный канал, что другие query-ошибки в проекте).
6. **AC-6 (регресс нулевой).** `npm run gate` зелёный — `ChangelogPage.test.tsx`, `changelog-routing.test.tsx`, `changelog-footer-nosha.test.tsx` не сломаны.
