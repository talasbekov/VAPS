# Story 13.1b: Багрепорт — кнопка (фронт)

Status: ready-for-dev

## Story

As a **оператор**,
I want **кнопку «сообщить о проблеме» в шапке портала (доступна с ЛЮБОГО экрана), авто-прикладывающую экран/версию/последние request_id, с формой на одно поле «что произошло»**,
so that **стоимость репорта ~0 — не нужно ничего искать/копировать вручную, «сообщить» = один клик + одна строка текста**.

Вторая половина буквы стори 13.1 (`epics.md#L1348-1353`) — бэкенд (13.1a, `POST /api/bugreports/`) уже done.

## Acceptance Criteria

1. **AC-1 (кнопка в шапке, на КАЖДОМ экране портала).** `BugReportButton` — новый компонент в `frontend/src/shared/ui/`, рендерится в `AppLayout.tsx`'s `<header>` рядом с `NotificationBell`/`ConnectionIndicator` (тот же слой — общий каркас, не per-фичевая копия). `shared → features` запрещён (ARCH-FE-013, уже задокументировано в `AppLayout.tsx`'s собственных комментариях про `AppFooter`) — компонент живёт в `shared/ui`, НЕ в `features/`.
2. **AC-2 (авто-контекст — экран/версия/request_id, оператор ничего не вводит).** При открытии формы автоматически собираны: `screen_path` (`useLocation().pathname`, паттерн `shared/auth/guards.tsx`), `app_version`/`build_sha` (`APP_VERSION`/`BUILD_SHA` из `shared/version.ts`, уже используются `AppFooter`), `last_request_ids` (последние N ответных `X-Request-Id`-заголовков — НОВЫЙ трекинг, backend его не хранит, см. Dev Notes).
3. **AC-3 (форма — одно поле, отправка).** Модалка на нативном `<dialog>`+`showModal()` (паттерн `ConflictDialog.tsx` — ЕДИНСТВЕННЫЙ headless-модальный примитив в проекте, не изобретать новый). Одно текстовое поле «Что произошло» (свободный текст, непустой — бэк уже требует непустой `description`, фронт зеркалит той же валидацией, что паттерн `ConflictDialog`'s reason-непустоты, но БЕЗ длины 10–500 — та длина специфична конфликт-оверрайду, буква 13.1 не требует минимума для багрепорта). Кнопка «Отправить» → `useApiMutation` (сырой `useMutation` в `features/` забанен — но этот компонент в `shared/ui`, тот же прецедент `NotificationBell.tsx`, которая тоже в `shared/ui` и МОЖЕТ мутировать напрямую через `apiClient`+`useApiMutation`).
4. **AC-4 (успех/ошибка — тост, не тихий провал).** Успех — короткий тост «Спасибо, репорт отправлен» (паттерн `useToast`, уже используемый `useApiMutation`'s error-каналом). Сетевая/серверная ошибка — НЕ теряет введённый текст (модалка остаётся открытой с уже введённым текстом, паттерн `mutation.error`-рендера).
5. **AC-5 (типизация — реальный `schema.d.ts`, не any).** `npm run generate:api` перегенерирован ПОСЛЕ 13.1a (бэк уже добавил `/api/bugreports/` в `schema.yaml`) — компонент типизирован по реальному `components["schemas"]["BugReportCreateSerializer"]` (или сгенерированное имя), не ручным интерфейсом-дубликатом.
6. **AC-6 (регресс нулевой).** `npm run gate` (или `frontend`'s эквивалент) зелёный — существующие `AppLayout.test.tsx`/`notifications.spec.ts`-подобные e2e не ломаются новым элементом в шапке (проверить явно — `AppLayout.tsx`'s собственный комментарий уже предупреждает про хрупкие `listitem`-ассерты по всей странице, e2e-live/notifications-live.spec.ts).

## Dev Notes

- **`shared/ui`, не `features/`.** `AppLayout.tsx`'s собственные комментарии уже объясняют это правило дважды (`AppFooter`, `shared → features` запрещён ARCH-FE-013) — `BugReportButton` следует тому же ограничению: живёт в `shared/ui`, может свободно импортировать `shared/api`/`shared/version`.
- **`last_request_ids` — НОВАЯ инфраструктура, бэк её не даёт.** 13.1a's Dev Notes уже явно фиксируют: backend НЕ строит rolling-историю (`RequestContextMiddleware` — только per-request), фронт собирает сам из `X-Request-Id`-заголовков собственных ответов. Ring-buffer — простая структура (массив с cap), не over-engineering.
- **`<dialog>`+`showModal()`, не изобретать модалку заново.** `ConflictDialog.tsx` — единственный существующий прецедент (headless, focus-trap/Escape нативные, `useEffect`+`.open`-guard для StrictMode). Копировать структуру, не CSS.
- **`useApiMutation` в `shared/ui`, legal.** Комментарий `useApiMutation.ts`'s самого верха: «Сырой useMutation в src/features/** забанен eslint-ом; здесь (shared/api) легален» — это про САМ файл `useApiMutation.ts`. `NotificationBell.tsx` (тоже `shared/ui`) уже ИМПОРТИРУЕТ и использует `useApiMutation`/`apiClient` напрямую — тот же паттерн для `BugReportButton`.
- **Валидация длины НЕ копировать с `ConflictDialog`.** `REASON_MIN`/`REASON_MAX` (10–500) — специфичны конфликт-оверрайду (BR-003), буква 13.1 не требует минимума для «что произошло» — фронт зеркалит бэк: непустая строка (trim), не более.
