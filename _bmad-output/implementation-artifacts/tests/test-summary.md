## Контекст

Стори 8.8 — печатный каркас: print-route `/print/test` вне AppLayout за
`RequireAuth`, голый семантический HTML + `print.css` (скоуп `.print-root`),
6 вендоренных woff2 PT Serif (казахская кириллица), block-scoped eslint-канон
print-forms и НОВАЯ минимальная Playwright-инфра (chromium, без бэка, против
продакшн-сборки `vite preview`, вне gate — Д4). Первая стори с настоящим
браузерным e2e-раннером в проекте.

Dev-стори принесла смок `e2e/print.spec.ts` — 5 ассертов РОВНО по AC 8 (а–д):
DOM-скан классов, типографика 16/12/8pt, fonts.check казахских глифов, скрытие
подсказки под print-медиа, негативный контроль утечки на /login. QA-проход искал
e2e-верифицируемые AC сверх этого — в первую очередь computed styles, которые
jsdom не судит вовсе (Ловушка 11).

## Найденные пробелы покрытия (auto-applied, e2e 5 → 10)

Все закрыты новым файлом **`frontend/e2e/print-qa.spec.ts`** (5 тестов;
канонический смок AC 8 не тронут — на его «5/5» ссылается Debug Log стори):

1. **Auth-гейт существовал только в jsdom** (AC 1) — смок сидит credential в
   `beforeEach` для всех тестов, редирект незалогиненного на продакшн-сборке
   не был доказан браузером. Закрыто (е): без сида `/print/test` →
   `toHaveURL(/\/login$/)`, форма входа видна, `.print-root` отсутствует —
   критический негативный кейс.
2. **«Вне AppLayout» — только jsdom** (AC 1). Закрыто (ж): в реальном браузере
   на `/print/test` нет ни `navigation`, ни `banner`-лендмарка (печатный
   `<header>` внутри `<main>` banner'ом по HTML-AAM не является).
3. **Жирный итог «Общее» не проверялся НИГДЕ** (AC 5): `font-weight: 700` из
   `tfoot td` — computed style, юнит-гвард его не видит, смок (б) мерил только
   размеры. Закрыто (з): у ячейки «Общее» `font-weight ≥ 700` и семейство
   PT Serif; там же — казахская шапка через `getByRole('heading')` и
   ИИН-маска `^\*{6}\d{4}$` в каждой строке tbody (контракт doc-print).
4. **Границы таблицы не проверялись НИГДЕ** (AC 3): Tailwind preflight границы
   стёр — print.css обязан задать их сам (Ловушка 2), а регресс селектора
   `border` не ловился ни одним судьёй. Закрыто (и): `border-collapse:
   collapse` на table, `solid` >0px на ячейке.
5. **Print-медиа: проверялось только скрытие подсказки** (AC 8г) — регресс вида
   «спрятали весь .print-root» смок бы не заметил. Закрыто (к): под
   `emulateMedia({ media: 'print' })` подсказка hidden, но h1/таблица/примечание
   остаются видимыми (юридический артефакт печатается целиком).
